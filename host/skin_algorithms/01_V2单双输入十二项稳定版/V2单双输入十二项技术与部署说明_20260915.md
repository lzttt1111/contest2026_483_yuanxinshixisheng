# V2单RGB与四光源十二项技术与部署说明

## 1. 系统架构

```text
本地或云端输入
  → 输入身份、格式、质量与Profile检查
  → DermaVision、痤疮与皱纹常驻检测服务
  → 十二项正式结果
  → 十一模块量化与评分
  → JSON、CSV、检测图及可选双Word报告
```

本地入口为 `run.py`，云端启动入口为 `run_cloud_worker.py`，CPU评分汇总位于 `src/summary/`。

## 2. 输入模式

consumer接受普通RGB图片。institution使用签名采集清单，严格包含RGB_M、PP_M、CP_M和UV_M/365_M。RGB负责基础几何与普通检测；PP用于油光；CP用于红区、Brown和血管；UV用于UV色斑和紫质。跨通道处理必须通过配准和授权检查，不得静默替换光源。

## 3. 检测与评分

十二项检测映射为十一份报告模块。评分实现与资产位于 `calibration/`、`scoring_calibration/`、`src/summary_scoring/`、`src/summary/`、`src/aisia_medical_report/`、`00_runtime_assets/` 和 `templates/`。

缺少必要证据时返回不可评估，不使用0补齐缺失。合法零目标与缺测分开记录。评分版本、字段清单SHA和参考资产SHA参与任务身份。

## 4. 运行资产

模型位于 `models/`，厂家四光源sidecar位于 `00_runtime_assets/vendor_skin/`，评分参考和Word模板均随目录提供，Pydantic合同位于 `vendor/aisia-contracts/`。任何必需资产缺失或SHA不一致时必须失败关闭。

## 5. 安装

```bash
uv python install 3.10
uv lock --check
uv sync --frozen
python3 scripts/verify_submission_snapshot.py
```

推荐Ubuntu 22.04、Python 3.10、NVIDIA GPU和与锁定PyTorch版本兼容的驱动。三个参赛模块应使用各自独立的虚拟环境。

## 6. 本地运行

```bash
uv run --frozen python run.py --input-dir /data/input/rgb \
  --output-dir /data/output/consumer --capture-profile consumer --algorithms all
```

```bash
uv run --frozen python run.py --capture-manifest /data/input/capture_manifest.json \
  --capture-alias case-001 --output-dir /data/output/institution \
  --capture-profile institution --stop-on-error
```

完整参数以 `python run.py --help` 为准。Word默认关闭，需要时显式开启。

## 7. 云端Worker

systemd模板位于 `deploy/dermavision@.service`。十一检测任务产生十二项结果，其中purple同时产生UV色斑与紫质；summary为独立CPU任务。云端返回六字段信封：record_id、status、schema_version、meta_data、raw_result、debug_info。部署命令及队列映射见 `deploy/README.md`。 安装consumer target时执行：

```bash
sudo cp deploy/dermavision-consumer-workers.target /etc/systemd/system/
```

## 8. 输出与校验

每个样本保存十二项正式媒体、逐项量化文件、完整量化JSON、结果索引和运行回执。公开结果不得包含模型路径、临时目录、设备调试字段或凭据。

```bash
python3 scripts/verify_submission_snapshot.py
uv lock --check
```

`PACKAGE_MANIFEST.json`记录源码、模型和评分资产SHA256。校验不启动GPU。

## 9. 部署边界

本模块包含算法、模型、Worker、评分和报告代码，不包含Redis、数据库、对象存储服务、业务后端或生产密钥。正式上线前仍需完成目标服务器、消息队列、存储权限、GPU驱动和真实输入验收。
