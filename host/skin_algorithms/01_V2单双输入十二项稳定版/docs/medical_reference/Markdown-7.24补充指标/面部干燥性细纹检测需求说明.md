# **面部干燥性细纹检测需求说明**

# 一、系统目标

系统通过用户的标准化正面及左右侧面照片，识别眼下、颧部和面颊区域内短、细、浅、密集且多方向交织的细碎纹理，形成独立的面部干燥性细纹检测报告。

本报告主要评价：

**照片中呈现的干燥样细纹外观，包括细纹密度、细小尺度、区域网络覆盖、多方向交织程度、视觉对比度及左右分布。**

最终报告应回答以下问题：

- 面部是否存在明显的细碎、密集细纹外观；

- 细纹主要集中于眼下、颧部还是面颊；

- 单位面积细纹长度及网络覆盖范围是否较高；

- 细纹是否以短、窄、小尺度纹路为主；

- 纹理是否呈多方向交织和网状分布；

- 左右眼下、颧部或面颊是否存在差异；

- 本次结果是否具有足够的图像检测可信度。

本报告不直接评价：

- 皮肤角质层含水量；

- 经皮水分流失或皮肤屏障功能；

- 稳定性线性皱纹；

- 法令纹、木偶纹、颊中沟、泪沟等结构性沟槽；

- 皮肤干燥的具体原因及医学诊断。

# 二、医学定义

## 2.1 干燥性细纹

本报告中的“干燥性细纹”是指照片中呈现的干燥样细纹外观，主要表现为短、细、浅、密集、多方向交织的细碎纹理。

该名称用于描述与皮肤干燥状态常见外观相近的图像表型，不表示设备直接测得皮肤缺水、含水量下降或屏障受损。

干燥性细纹通常具有以下特点：

- 以区域性细碎纹理为主要表现；

- 单条纹路通常较短、较窄；

- 方向分散，交叉点和分支点相对较多；

- 多条细纹可形成网状或交织样覆盖；

- 通常缺少大尺度、宽而深的三维沟槽表现。

## 2.2 与其他纹路表型的区别

| **纹路类型** | **主要区别** |
| --- | --- |
| 干燥性细纹 | 以短、细、浅、密集和多方向交织的区域性纹理为主。 |
| 稳定性线性皱纹 | 以相对较长、较连续、方向较明确并可在多图中稳定识别的线状纹路为主。 |
| 结构性沟槽 | 以宽、长、深的大尺度解剖性沟槽和三维曲面变化为主。 |

三类纹路报告相互独立，不要求对每条候选纹路进行互斥分类。本报告只评价干燥性细纹图像表型。

## 2.3 医学解释边界

干燥性细纹评分反映照片中的细碎、密集、交织样纹理外观，不代表设备直接测得皮肤含水量、经皮水分流失、角质代谢或皮肤屏障状态。

# 三、主要检测区域

建议对以下面部区域分别检测：

- 左眼下；

- 右眼下；

- 左颧部；

- 右颧部；

- 左面颊；

- 右面颊。

## 3.1 重点检测区域

| **检测区域** | **重点识别表现** |
| --- | --- |
| 眼下 | 短、细、密集、多方向交织的浅表细纹网络。 |
| 颧部 | 细碎纹理密度、窄细纹比例及区域网络覆盖。 |
| 面颊 | 较分散的细小纹理及是否形成连续区域性细纹负担。 |

## 3.2 分区检测的医学意义

- 判断干燥性细纹主要集中于眼下、颧部还是面颊；

- 比较左右对应区域的细纹密度和网络覆盖；

- 区分局部眼下细纹与较广泛面颊细碎纹理；

- 评价治疗或护理前后不同区域的变化。

## 3.3 无效或需谨慎检测区域

- 睫毛、眉毛和头发遮挡区域；

- 下眼睑边缘及结膜暴露区域；

- 明显底妆卡粉或护肤品残留区域；

- 严重高光、阴影、曝光异常或图像压缩区域；

- 图像分辨率不足、无法稳定识别细碎纹理的区域。

| 左右不对称 | 左右眼下网络覆盖率差异 | 反映左右眼下细纹网络覆盖范围是否一致。 |

| 左右不对称 | 左右面颊细纹负担差异 | 反映左右面颊细碎纹理负担是否一致。 |
| 检测可信度 | 有效图像区域比例 | 反映目标区域中具备足够清晰度和标准曝光的有效皮肤面积。 |
| 检测可信度 | 妆容或产品残留干扰程度 | 反映底妆卡粉、护肤品或防晒残留对细碎纹理识别的影响。 |
| 检测可信度 | 多图纹理表现一致性 | 反映同一细纹区域在不同角度照片中的总体纹理负担是否一致。 |

# 五、干燥性细纹评分组成

干燥性细纹综合评分建议由以下指标组共同参与：

| **评分组成** | **建议初始权重** | **评分意义** |
| --- | --- | --- |
| 常见部位匹配 | 20% | 评价细碎纹理是否主要位于眼下、颧部和面颊等常见区域。 |
| 细纹密度 | 25% | 评价单位面积细纹总长度、细纹数量及高密度区域负担。 |
| 细小尺度 | 20% | 评价短纹、窄纹和小面积纹路的比例。 |
| 交织网络 | 20% | 评价多方向分布、交叉点、分支点及网络覆盖。 |
| 浅表视觉特征 | 15% | 评价低至中等对比度、短断续表现及缺少大尺度深沟的程度。 |

检测可信度不足时，应保留结果作为提示，并明确标注可能存在妆容、产品残留、光照或图像分辨率干扰。

以上权重为第一版医学指导建议，后续可根据医学专家标注、皮肤含水相关参考测量、重复拍摄结果及模型训练数据进行调整。

# 六、分区评分与结果等级

## 6.1 分区评分

建议分别输出以下区域的干燥性细纹评分：

- 左眼下评分；

- 右眼下评分；

- 左颧部评分；

- 右颧部评分；

- 左面颊评分；

- 右面颊评分；

- 全面部干燥性细纹评分。

每个分区评分应综合反映：

- 细纹数量和长度密度；

- 短细纹及窄细纹比例；

- 细纹网络覆盖率；

- 方向分散程度；

- 交叉点和分支点密度；

- 多方向交织程度；

- 视觉对比度及浅表形态；

- 检测可信度。

分区结果用于定位主要受累区域，不应只输出一个全面部总分。

## 6.2 结果等级

第一版可暂时采用以下图像学等级：

| **综合评分** | **等级** |
| --- | --- |
| 0～20分 | 未见明显 |
| 21～40分 | 轻度 |
| 41～60分 | 中度 |
| 61～80分 | 较明显 |
| 81～100分 | 显著 |

以上等级属于基于照片及3D模型的干燥性细纹图像学分级，不代表组织学损伤程度或具体疾病严重程度。

具体分界值后续应根据以下数据进行重新标定：

- 医学专家视觉评分；

- 参考人群分布；

- 不同年龄及肤质人群数据；

- 标准化重复拍摄结果；

- 系统实际检测表现。

## 7.1 一级结果

- 干燥性细纹综合评分；

- 干燥性细纹等级；

- 主要受累区域；

- 左右不对称情况；

- 检测可信度。

## 7.2 二级结果

- 细纹密度负担；

- 细小尺度表现；

- 细纹网络覆盖；

- 多方向交织程度；

- 浅表视觉特征；

- 各面部分区评分。

## 7.3 核心指标

- 单位面积细纹总长度；

- 细纹网络覆盖率；

- 窄细纹比例；

- 短细纹比例；

- 交叉点密度；

- 方向分散程度；

- 主要受累区域；

- 左右眼下差异。

## 7.4 可视化结果

- 细纹网络覆盖区域；

- 高密度细纹区域重点标记；

- 多方向交织纹理显示；

- 分区细纹负担图；

- 左右差异提示；

- 低可信度或干扰区域提示。

干燥性细纹以区域性细碎纹理为主要检测对象，不要求在用户报告中展示每一条极细纹路的独立轮廓。

## 7.5 干燥性细纹报告示例

### 干燥性细纹：47分，中度

双侧眼下是最需要关注的区域，右侧略高于左侧。

眼下区域可见较多短、细、密集且多方向交织的纹理，细纹长度密度和网络覆盖率偏高；颧部存在中度细碎纹理，面颊区域相对较轻。

综合表现提示中度干燥性细纹外观。本结果反映照片中的干燥样细碎纹理，不代表设备直接测得皮肤含水量或屏障功能。

| --- | --- | --- |
| 左眼下 | 61分 | 细纹密度和交织程度较高 |
| 右眼下 | 66分 | 细纹网络覆盖率较高 |
| 左颧部 | 42分 | 中度细碎纹理 |
| 右颧部 | 45分 | 中度细碎纹理 |
| 左面颊 | 28分 | 轻度细纹负担 |
| 右面颊 | 31分 | 轻度细纹负担 |

> **分区日常注释：** 分区分数用于比较同一次检测中不同部位的细纹外观。眼下分数较高时，可优先加强温和保湿和防晒，并减少揉搓或过度清洁。

### 核心指标示例

| **核心指标** | **检测结果** | **结果解释** |
| --- | --- | --- |
| 单位面积细纹总长度 | 眼下偏高 | 双侧眼下细纹密度较明显 |
| 细纹网络覆盖率 | 右眼下偏高 | 右眼下细碎纹理覆盖范围较大 |

| 多方向交织程度 | 中度偏高 | 细纹方向分散并形成交织网络 |
| 重点区域 | 双侧眼下 | 干燥性细纹主要集中于眼下区域 |
| 左右差异 | 右侧略高 | 右眼下网络覆盖和细纹密度略高于左侧 |

> **关键指标日常注释：** “单位面积细纹总长度”表示同样面积内细纹有多密集；“细纹网络覆盖率”表示交织细纹覆盖了多大范围；“窄细纹比例”较高说明以细小浅纹为主；“多方向交织程度”越高，纹理看起来越密、越杂。以上指标适合用于安排日常保湿重点和观察同条件复测变化。

# 八、医学说明、检测局限性与最终医学逻辑

## 8.1 医学说明与检测局限性

干燥性细纹检测结果反映标准化照片中的：

- 细纹数量和长度密度；

- 细纹宽度及细小尺度；

- 细纹网络覆盖范围；

- 方向分散和交织程度；

- 视觉对比度；

- 分区分布和左右差异；

- 图像检测可信度。

本报告不能直接判断：

- 皮肤角质层含水量；

- 经皮水分流失；

- 皮肤屏障是否受损；

- 角质代谢是否异常；

- 细纹形成的具体病因。

检测结果可能受到以下因素影响：

- 底妆卡粉、遮瑕或粉体残留；

- 护肤品和防晒产品残留；

- 光照、曝光及局部高光；

- 图像压缩和分辨率；

- 面部表情及眼周牵拉；

- 毛发和睫毛遮挡；

- 拍摄距离和角度。

治疗前后或不同时间检测时，应尽量保持相同的拍摄设备、光照、距离、角度、面部表情和产品使用状态。

## 8.2 最终医学逻辑

干燥性细纹报告是一个独立的面部细碎纹理图像表型报告。

其核心评价内容为：

眼下、颧部和面颊区域内的细纹是否短、细、密集，覆盖范围有多广，是否形成多方向交织网络，以及主要分布在哪里。

本报告使用“干燥性细纹”描述干燥样细纹外观，但不能替代皮肤含水量、经皮水分流失或皮肤屏障功能的直接测量。
