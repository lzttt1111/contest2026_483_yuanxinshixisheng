# **面部弥漫性泛红检测需求**

# 一、系统目标

通过VISIA红色区、标准白光图像和可见红色色差图层，识别面部大面积、连续、边界相对模糊的背景性红色信号，评价弥漫性泛红的面积、强度、连续性、边界渐变、均匀性及分布，形成独立的面部弥漫性泛红检测报告。

本报告主要评价：

**在排除独立红色丘疹、毛囊周围红斑、丘脓疱样目标和线状血管结构后，面部背景皮肤整体呈现的连续性泛红外观。**

最终报告应回答以下问题：

- 面部是否存在大面积背景性泛红；

- 泛红覆盖范围和红色强度有多大；

- 是否形成大片连续红色区域；

- 泛红边界是否呈渐变和模糊过渡；

- 泛红在区域内是相对均匀还是斑驳；

- 标准白光与VISIA红色区是否共同支持背景泛红；

- 主要集中于中央面部、双侧面颊还是其他区域；

- 左右两侧是否存在明显差异。

本报告不直接评价：

- 独立局灶性红色丘疹；

- 毛囊周围红斑；

- 毛囊性丘疹或丘脓疱样目标；

- 线状血管样结构；

- 皮肤屏障功能；

- 皮肤敏感程度；

- 玫瑰痤疮、皮炎或过敏性疾病的临床诊断。

# 二、医学定义

## 2.1 弥漫性泛红表型

本报告中的“弥漫性泛红”是指：

**标准化面部图像中呈大面积、连续或相互融合、边界相对模糊的背景性红色信号。**

该表型可与弥漫性浅表血管扩张、炎症相关背景泛红或刺激后泛红样反应相符，但不能单独确定具体病因。

## 2.2 主要检测图层

本项目主要使用以下图像信息：

- VISIA红色区中的弥漫性红色部分；

- 标准白光图像中的背景红色；

- 可见红色色差图层中的片状、连续红色部分；

- 面部分区；

- 局灶性红色目标排除结果；

- 线状血管目标排除结果；

- 毛囊性红色目标排除结果。

弥漫性泛红评价应以排除独立目标后的背景红色为基础，避免将丘疹、毛囊红斑或线状血管重复计入。

# 三、主要检测区域

建议对以下面部区域分别检测：

- 额部；

- 眉间；

- 鼻部；

- 左鼻旁；

- 右鼻旁；

- 左面颊；

- 右面颊；

- 左颧部；

- 右颧部；

- 口周；

- 下颌。

其中重点报告区域包括：

- 双侧面颊；

- 鼻部及鼻旁；

- 中央面部。

## 3.1 分区检测的医学意义

分区检测可以用于：

- 判断泛红主要集中于哪些区域；

- 区分中央面部泛红与全面部广泛泛红；

- 比较双侧面颊及鼻旁的红色面积和强度；

- 识别明显单侧泛红；

- 评价治疗、护理或刺激前后的区域变化。

不同分区面积不同，因此跨区域比较时，应优先使用红色面积占比、强度和高强度红色面积占比，而不是只比较红色总面积。

# 四、需要检测的指标及医学意义

| **指标项目** | **需要检测的具体指标** | **医学意义** |
| --- | --- | --- |
| 泛红面积 | 分区弥漫红色面积 | 反映各面部分区内背景性红色的实际覆盖范围。 |
| 泛红面积 | 全面部弥漫红色总面积 | 反映全面部背景性泛红的总体范围。 |
| 泛红面积 | 分区弥漫红色面积占比 | 反映背景红色面积占相应分区有效皮肤面积的比例。 |
| 泛红面积 | 全面部弥漫红色面积占比 | 反映全面部有效皮肤区域中背景泛红的总体比例。 |
| 红色强度 | 平均红色强度 | 反映背景皮肤整体典型泛红程度。 |
| 红色强度 | P90红色强度 | 反映较明显泛红区域的红色水平。 |
| 高强度泛红负担 | 高强度红色总面积 | 反映明显泛红区域的总覆盖范围。 |
| 高强度泛红负担 | 高强度红色面积占比 | 反映明显泛红区域占有效皮肤面积的比例。 |
| 连续性 | 最大连续红色区域面积 | 反映是否形成大片连续背景泛红区域。 |
| 连续性 | 红色区域连续性 | 反映背景红色是否呈连续片状分布，而不是由大量独立小目标组成。 |
| 边界与均匀性 | 边界渐变程度 | 反映红色区域与周围皮肤之间是否呈模糊渐变过渡。 |
| 边界与均匀性 | 区域内红色均匀度 | 反映泛红在同一区域内是相对均匀还是斑驳。 |
| 图像一致性 | 白光与VISIA红色区重叠率 | 反映标准白光与VISIA红色区是否共同支持背景泛红。 |
| 分区分布 | 中央面部集中程度 | 反映泛红是否主要集中于鼻部、鼻旁和面颊中央。 |
| 分区分布 | 泛红受累分区数量 | 反映弥漫性泛红影响的面部范围。 |
| 分区分布 | 主要泛红区域 | 用于判断泛红主要集中于面颊、鼻旁、鼻部、额部或其他区域。 |
| 左右不对称 | 左右面颊红色面积占比差异 | 反映左右面颊背景泛红覆盖范围是否一致。 |
| 左右不对称 | 左右鼻旁P90红色强度差异 | 反映左右鼻旁较明显泛红区域的红色程度是否存在差异。 |
| 背景泛红校正 | 排除局灶目标后的红色面积占比 | 反映去除丘疹、毛囊红斑、丘脓疱及线状血管后的背景红色负担。 |
| 背景泛红校正 | 排除局灶目标后的P90红色强度 | 反映去除独立目标后较明显背景泛红区域的红色水平。 |

# 五、弥漫性泛红评分组成

弥漫性泛红综合评分建议由以下指标组共同参与。

| **评分组成** | **建议初始权重** | **评分意义** |
| --- | --- | --- |
| 红色面积及连续性 | 30% | 评价背景泛红的覆盖范围及是否形成大片连续区域。 |
| 红色强度 | 25% | 评价典型及较明显背景泛红区域的红色程度。 |
| 白光与VISIA一致性 | 20% | 评价背景泛红是否由两种图像共同支持。 |
| 边界渐变及背景均匀性 | 15% | 评价泛红是否符合边界模糊、连续背景红色的外观。 |
| 面部分布及左右差异 | 10% | 评价主要受累区域、中央面部集中程度及左右不对称。 |

局灶性炎症样目标、毛囊性目标及线状血管目标不直接计入弥漫性泛红评分，避免重复计算。

以上权重为第一版医学指导建议，后续可根据医学专家视觉评分、参考人群数据、重复拍摄稳定性和模型验证结果进行调整。

# 六、分区评分与结果等级

## 6.1 分区评分

建议分别输出以下区域的弥漫性泛红评分：

- 额部评分；

- 眉间评分；

- 鼻部评分；

- 左鼻旁评分；

- 右鼻旁评分；

- 左面颊评分；

- 右面颊评分；

- 左颧部评分；

- 右颧部评分；

- 口周评分；

- 下颌评分。

同时建议输出中央面部泛红评分和全面部弥漫性泛红评分。

每个分区评分应综合反映红色面积占比、P90红色强度、高强度红色面积占比、连续性、边界渐变、图像一致性及背景泛红校正结果。

## 6.2 结果等级

| **综合评分** | **等级** |
| --- | --- |
| 0～20分 | 未见明显 |
| 21～40分 | 轻度 |
| 41～60分 | 中度 |
| 61～80分 | 较明显 |
| 81～100分 | 显著 |

以上等级属于弥漫性泛红图像表型分级，不代表具体疾病严重程度。具体分界值后续应根据医学专家标注和参考人群数据重新标定。

# 七、最终报告内容与示例

## 7.1 一级结果

- 弥漫性泛红综合评分；

- 结果等级；

- 主要泛红区域；

- 中央面部集中程度；

- 白光与VISIA一致性；

- 左右不对称情况。

## 7.2 二级结果

- 泛红面积负担；

- 泛红强度表现；

- 高强度泛红负担；

- 背景红色连续性；

- 边界渐变及均匀性；

- 排除局灶目标后的背景红色负担；

- 各面部分区评分。

## 7.3 核心指标

报告中建议展示以下核心指标：

- 弥漫红色面积占比；

- P90红色强度；

- 高强度红色面积占比；

- 最大连续红色区域面积；

- 白光与VISIA重叠率；

- 排除局灶目标后的红色面积占比；

- 主要受累区域；

- 左右差异。

## 7.4 可视化结果

- 弥漫性背景红色区域标记；

- 高强度泛红区域标记；

- 最大连续泛红区域；

- 排除的局灶性红色目标提示；

- 分区泛红负担图；

- 左右差异提示。

弥漫性泛红区域与局灶性红色目标、毛囊性红色目标及线状血管样结构应使用不同的可视化方式。

## 7.5 报告示例

### 弥漫性泛红评分：68分，较明显

双侧面颊和鼻旁是最需要关注的区域。

泛红覆盖范围约占有效检测区域的24.6%，其中颜色较明显的泛红区域占6.8%。双侧面颊可见大片连续、边界渐变的成片泛红，标准白光图像与VISIA红色区具有较高一致性。

在排除局灶性红色丘疹、毛囊周围红斑和线状血管后，成片泛红负担仍然较高。

整体呈较明显的持续泛红外观，右侧面颊略重于左侧。

本结果不能单独用于诊断敏感肌、皮肤屏障受损或玫瑰痤疮。

### 分区结果示例

| **面部分区** | **评分** | **主要表现** |
| --- | --- | --- |
| 左面颊 | 70分 | 泛红面积占比及连续性较高 |
| 右面颊 | 74分 | 红色强度和高强度面积占比较高 |
| 左鼻旁 | 65分 | 较明显背景泛红 |
| 右鼻旁 | 68分 | 泛红强度略高于左侧 |
| 鼻部 | 58分 | 中度泛红 |

> **关键指标日常注释：** “泛红面积占比”表示泛红覆盖范围；“较强泛红程度”表示颜色更明显区域的红度；“较明显泛红面积占比”表示较红区域占了多大范围；“连续性”用于区分成片泛红和零散红点。日常可观察换季、冷热刺激、清洁或更换护肤品前后的变化。

# 八、医学说明、检测局限性与最终医学逻辑

## 8.1 医学说明与检测局限性

面部弥漫性泛红检测结果反映标准化图像中的：

- 背景红色面积；

- 背景红色强度；

- 高强度红色负担；

- 连续性；

- 边界渐变；

- 区域内均匀性；

- 图像一致性；

- 分区分布；

- 左右差异。

本报告不能直接判断：

- 皮肤屏障是否受损；

- 皮肤是否属于敏感肌；

- 是否存在玫瑰痤疮、接触性皮炎、激素相关皮炎或过敏性炎症；

- 泛红的具体病因；

- 真实血流量或血管反应性。

检测结果可能受到环境温度、运动、情绪、饮酒、清洁刺激、护肤品、妆容、光照、曝光、肤色差异和拍摄时间影响。治疗前后或不同时间检测时，应尽量保持相同拍摄条件和检测前状态。

## 8.2 最终医学逻辑

面部弥漫性泛红报告是一个背景性红色图像表型报告。

其核心评价内容为：

**在排除独立局灶目标和线状血管结构后，面部背景皮肤有多红、覆盖多广、是否连续、边界是否渐变，以及主要分布在哪里。**
