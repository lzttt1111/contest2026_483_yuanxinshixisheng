# **面部毛囊炎症及痤疮检测需求**

# 一、系统目标

通过VISIA红色区、标准白光图像、可见红色色差图层、VISIA毛孔位置、VISIA紫质及必要的多角度图像形态信息，识别面部局灶性炎症样红色目标和毛囊中心性炎症及痤疮样目标，形成独立的面部毛囊炎症及痤疮检测报告。

本报告包含两个相互关联但分别评价的结果：

1. 非明确毛囊性的局灶性炎症样红色表现；

2. 毛囊中心性的毛囊炎症及痤疮样表现。

本报告主要评价：

**面部独立红色目标是否伴局部隆起或白黄中心，以及这些目标是否以毛囊为中心、是否伴毛囊内卟啉荧光信号。**

最终报告应回答以下问题：

- 面部是否存在独立点状或小片状炎症样红色目标；

- 这些目标是平坦红斑样、丘疹样还是丘脓疱样；

- 红色、隆起和白黄中心是否属于同一个空间目标；

- 目标是否明确以毛囊或毛孔为中心；

- 毛囊中心性目标是否伴紫质信号；

- 各类目标的数量、密度、面积、红色强度和聚集程度如何；

- 主要集中于哪些面部区域；

- 左右两侧是否存在明显差异。

本报告不直接评价：

- 痤疮或毛囊炎的确定性诊断；

- 痤疮与毛囊炎的确定性鉴别；

- 细菌性或真菌性病因；

- 具体病原体类型；

- 毛囊内细菌绝对数量；

- 炎症介质水平；

- 白黄中心是否为真实脓液；

- 皮损触痛、瘙痒及病程信息。

# 二、医学定义

## 2.1 局灶性炎症样红色目标

局灶性炎症样红色目标是指与周围正常皮肤具有相对明确边界的点状或小片状红色目标，毛囊中心定位不明确。包括：

- 平坦局灶红斑样目标：无明显隆起、无白黄中心；

- 非明确毛囊性的红色丘疹样目标：伴局部隆起、无白黄中心；

- 非明确毛囊性的丘脓疱样目标：伴局部隆起并存在白色或黄色中心。

该部分主要反映局部活动炎症样红色表型或红色印记样外观，不能单独确定具体疾病。

## 2.2 毛囊中心性炎症及痤疮样目标

毛囊中心性目标要求红色、隆起或白黄中心与毛孔或毛囊中心具有较高空间匹配度。包括：

- 毛囊周围红斑样目标：毛囊周围存在环状、点状或小片状红色，无明确隆起和白黄中心；

- 毛囊性红色丘疹样目标：以毛囊为中心，伴局部红色隆起，无明确白黄中心；

- 毛囊性丘脓疱样目标：以毛囊为中心，伴红色隆起和白色或黄色中心。

## 2.3 毛囊卟啉的评价意义

VISIA紫质反映毛囊内卟啉相关荧光信号，用于判断毛囊性红色或隆起目标是否与卟啉阳性毛囊存在空间关联。

- 紫质明显可以增强目标与卟啉阳性毛囊相关的证据；

- 紫质不明显不能排除真实毛囊炎症；

- 紫质不能直接表示毛囊内细菌数量、感染程度、炎症严重度或具体病原体。

## 2.4 两类结果的关系

非明确毛囊性的局灶性炎症样红色结果与毛囊中心性炎症结果分别评分。非明确毛囊性目标不直接计入毛囊炎症及痤疮样活动总分，避免将非毛囊性局部炎症与毛囊皮脂腺单位相关炎症混为同一类。

# 三、主要检测区域

建议对以下面部区域分别检测：

- 额部；

- 鼻部及鼻旁；

- 左颧部；

- 右颧部；

- 左面颊；

- 右面颊；

- 口周；

- 左下颌；

- 右下颌。

其中重点报告区域包括：

- 额部；

- 双侧面颊；

- 下颌；

- 鼻部及鼻旁；

- 口周。

## 3.1 分区检测的医学意义

分区检测可以用于：

- 判断局灶性炎症样目标和毛囊性目标主要集中于哪些区域；

- 区分面颊、下颌、额部和口周的目标类型及负担；

- 评价目标是否呈局部成簇分布；

- 比较左右面颊和左右下颌的目标数量及严重程度；

- 评价治疗或护理前后不同类型目标的变化。

不同分区面积不同，因此跨区域比较时，应同时参考目标数量、单位面积密度、目标总面积占比和目标类型，而不是只比较绝对数量。

# 六、分区评分与结果等级

## 6.1 分区评分

建议分别输出以下区域的局灶性炎症样红色评分和毛囊炎症及痤疮样活动评分：

- 额部；

- 鼻部及鼻旁；

- 左颧部；

- 右颧部；

- 左面颊；

- 右面颊；

- 口周；

- 左下颌；

- 右下颌。

每个分区应分别展示平坦局灶红斑样目标、非明确毛囊性丘疹或丘脓疱样目标、毛囊周围红斑、毛囊性红色丘疹及毛囊性丘脓疱样目标的数量和主要负担。

## 6.2 结果等级

| **综合评分** | **等级** |
| --- | --- |
| 0～20分 | 未见明显 |
| 21～40分 | 轻度 |
| 41～60分 | 中度 |
| 61～80分 | 较明显 |
| 81～100分 | 显著 |

局灶性炎症样红色评分和毛囊炎症及痤疮样活动评分分别使用上述等级。以上等级属于图像表型分级，不代表痤疮、毛囊炎或其他炎症性疾病的临床严重程度。

# 七、最终报告内容与示例

# 八、医学说明、检测局限性与最终医学逻辑

## 8.1 医学说明与检测局限性

面部毛囊炎症及痤疮检测结果反映标准化图像中的：

- 独立红色目标；

- 局部隆起；

- 白色或黄色中心；

- 毛囊中心定位；

- 毛囊周围红色；

- 毛囊卟啉荧光关联；

- 目标数量、密度、面积及聚集；

- 分区分布及左右差异。

本报告不能直接判断：

- 是否确诊痤疮或毛囊炎；

- 痤疮与毛囊炎的确定性鉴别；

- 是否为细菌性或真菌性病因；

- 具体病原体；

- 毛囊内细菌数量；

- 白黄中心是否为真实脓液；

- 炎症介质水平；

- 皮损的触痛、瘙痒和病程。

检测结果可能受到妆容、护肤品、防晒、高光反射、毛发、图像清晰度、拍摄角度、近期清洁、外用药物和UV拍摄参数影响。多角度图像一致性和白黄中心置信度应作为重要质量控制信息。

## 8.2 最终医学逻辑

面部毛囊炎症及痤疮报告是一个局灶性红色和毛囊中心性炎症样图像表型报告。

其核心评价内容为：

**面部存在多少独立红色目标，这些目标是否伴隆起或白黄中心，是否以毛囊为中心，是否伴紫质信号，以及主要分布和聚集在哪里。**
