# **面部毛孔检测需求说明**

# 一、系统目标

通过标准化面部照片，检测面部可见毛孔的数量、大小、面积、形态、视觉明显程度及分布情况，形成独立的面部毛孔检测报告。

本报告主要评价：

**面部照片中达到系统识别标准的可见毛孔开口，以及这些毛孔对皮肤外观造成的视觉影响。**

最终报告应回答以下问题：

- 面部可见毛孔数量是否较多；

- 毛孔是否存在明显粗大；

- 毛孔在皮肤表面的覆盖范围有多大；

- 毛孔主要呈圆形、椭圆形还是拉长形态；

- 毛孔主要集中在哪些面部区域；

- 左右两侧毛孔负担是否存在差异。

本报告不直接评价：

- 皮脂分泌量；

- 毛孔堵塞程度；

- 角栓数量；

- 皮脂丝数量；

- 痤疮切割杆菌数量；

- 毛孔真实深度；

- 毛囊皮脂腺功能；

- 毛孔粗大的具体病因。

# 二、医学定义

本报告中的“可见毛孔”是指：

**在标准化面部照片中，与周围皮肤相比呈现相对明确的点状、圆形、椭圆形或拉长形暗色开口，并达到系统识别标准的毛囊开口样目标。**

可见毛孔数量不等于面部真实毛囊总数。

部分毛囊开口可能因为以下原因未被识别：

- 毛孔开口较小；

- 毛孔与周围皮肤对比度较低；

- 图像清晰度不足；

- 局部曝光过高或过低；

- 毛发、妆容或护肤品遮挡；

- 拍摄角度导致毛孔表现不明显。

因此，本报告评价的是照片中的可见毛孔负担，而不是皮肤组织学层面的全部毛囊数量。

# 三、主要检测区域

建议对以下面部区域分别检测：

- 额部；

- 鼻部；

- 左鼻旁；

- 右鼻旁；

- 左内侧面颊；

- 右内侧面颊；

- 左外侧面颊；

- 右外侧面颊；

- 下巴。

其中重点报告区域包括：

- 鼻部；

- 鼻旁；

- 内侧面颊；

- 外侧面颊。

## 3.1 分区检测的医学意义

不同面部区域的可见毛孔数量、大小和形态存在差异。

分区检测可以用于：

- 判断毛孔问题主要集中在哪些区域；

- 区分鼻部毛孔密集与面颊毛孔粗大；

- 比较内侧面颊和外侧面颊的毛孔差异；

- 比较左侧和右侧面部的毛孔负担；

- 评价治疗或护理前后不同区域的改善情况。

不同分区面积不同，因此跨区域比较时，应优先使用：

- 单位面积毛孔密度；

- 毛孔面积占比；

- 大毛孔比例；

而不是只比较毛孔绝对数量或毛孔总面积。

# 四、需要检测的指标及医学意义

| **指标项目** | **需要检测的具体指标** | **医学意义** |
| --- | --- | --- |
| 毛孔数量 | 分区毛孔数量 | 反映各面部分区内达到系统识别标准的可见毛孔数量，可用于判断毛孔主要集中在哪些区域。 |
| 毛孔数量 | 全面部毛孔总数 | 反映全面部检测到的可见毛孔总量，但不代表皮肤真实毛囊总数。 |
| 毛孔数量 | 单位面积毛孔密度 | 反映单位皮肤面积内的可见毛孔数量，可减少不同面部分区面积差异对结果的影响。 |
| 毛孔大小 | 单个毛孔面积 | 反映每个可见毛孔在二维照片中的开口面积，是评价单个毛孔大小的基础指标。 |
| 毛孔大小 | P50毛孔面积 | 反映典型可见毛孔的面积水平，不易受到少量极大毛孔影响。 |
| 毛孔大小 | P90毛孔面积 | 反映偏大毛孔的面积水平，可用于评价较大一组毛孔的粗大程度。 |
| 毛孔大小 | 最大毛孔面积 | 反映单个最突出的可见毛孔面积，容易受到局部误检影响，仅作为辅助展示指标。 |
| 大毛孔负担 | 大毛孔数量 | 反映超过设定大小标准的粗大毛孔数量。具体大小标准后续根据医学标注和参考数据确定。 |
| 大毛孔负担 | 大毛孔比例 | 反映大毛孔数量占全部可见毛孔数量的比例，是评价毛孔粗大程度的重要指标。 |
| 大毛孔负担 | 大毛孔总面积 | 反映全部大毛孔在相应检测区域内形成的总面积负担。 |
| 大毛孔负担 | 大毛孔面积占比 | 反映大毛孔面积占有效皮肤面积或全部毛孔面积的比例，可评价大毛孔对整体毛孔外观的贡献。 |
| 毛孔面积负担 | 分区毛孔总面积 | 反映某一面部分区内全部可见毛孔面积的总和，综合受到毛孔数量和毛孔大小影响。 |
| 毛孔面积负担 | 全面部毛孔总面积 | 反映全面部所有可见毛孔在二维照片中的总覆盖面积。 |
| 毛孔面积负担 | 分区毛孔面积占比 | 反映某一分区内毛孔总面积占有效皮肤面积的比例，可用于不同区域之间的比较。 |
| 毛孔面积负担 | 全面部毛孔面积占比 | 反映全面部有效皮肤区域中被可见毛孔目标覆盖的比例，用于评价总体毛孔面积负担。 |
| 毛孔圆度 | 单个毛孔圆度 | 反映单个毛孔形态接近规则圆形的程度。 |
| 毛孔圆度 | P50毛孔圆度 | 反映全面部或某一分区内典型毛孔的圆度水平。 |
| 毛孔圆度 | 规则圆形毛孔比例 | 反映全部可见毛孔中形态接近规则圆形的毛孔占比。 |
| 毛孔圆度 | 低圆度毛孔比例 | 反映明显偏离规则圆形的毛孔占比，可用于描述毛孔形态改变。 |
| 毛孔长宽比 | 单个毛孔长宽比 | 反映单个毛孔长轴与短轴之间的差异。 |
| 毛孔长宽比 | P50毛孔长宽比 | 反映典型可见毛孔的长宽关系。 |
| 毛孔长宽比 | 椭圆形毛孔比例 | 反映具有明显椭圆形外观的毛孔占比。 |
| 毛孔长宽比 | 拉长毛孔比例 | 反映长宽比较高、呈明显拉长样外观的毛孔占比。 |
| 毛孔视觉对比度 | 单个毛孔对比度 | 反映单个毛孔与周围皮肤之间的明暗差。 |
| 毛孔视觉对比度 | 平均毛孔对比度 | 反映全面部或某一分区内全部毛孔的平均视觉明显程度。 |
| 毛孔视觉对比度 | P50毛孔对比度 | 反映典型可见毛孔的视觉明显程度。 |
| 毛孔视觉对比度 | P90毛孔对比度 | 反映较明显一组毛孔的对比度水平。 |
| 毛孔视觉对比度 | 高对比度毛孔数量 | 反映视觉上较明显的毛孔数量。 |
| 毛孔视觉对比度 | 高对比度毛孔比例 | 反映高对比度毛孔占全部可见毛孔的比例。毛孔对比度不等同于毛孔真实深度。 |
| 毛孔分布 | 各分区毛孔数量 | 反映不同面部分区内可见毛孔绝对数量的差异。 |
| 毛孔分布 | 各分区毛孔密度 | 反映不同区域单位面积内的毛孔数量负担。 |
| 毛孔分布 | 各分区毛孔总面积 | 反映不同区域全部可见毛孔的面积总和。 |
| 毛孔分布 | 各分区毛孔面积占比 | 反映不同区域毛孔覆盖皮肤表面的相对范围。 |
| 毛孔分布 | 各分区P90毛孔面积 | 反映不同区域偏大毛孔的大小水平。 |
| 毛孔分布 | 各分区大毛孔比例 | 反映不同区域粗大毛孔的相对负担。 |
| 毛孔分布 | 主要毛孔集中区域 | 用于判断毛孔问题主要集中于鼻部、鼻旁、内侧面颊、外侧面颊或其他区域。 |
| 左右不对称 | 左右鼻旁毛孔密度差异 | 反映左右鼻旁区域单位面积毛孔数量是否存在差异。 |
| 左右不对称 | 左右内侧面颊毛孔密度差异 | 反映左右内侧面颊可见毛孔数量负担是否一致。 |
| 左右不对称 | 左右外侧面颊毛孔密度差异 | 反映左右外侧面颊可见毛孔数量负担是否一致。 |
| 左右不对称 | 左右面颊毛孔面积占比差异 | 反映左右面颊毛孔覆盖范围是否存在差异。 |
| 左右不对称 | 左右P90毛孔面积差异 | 反映左右两侧偏大毛孔的大小水平是否一致。 |
| 左右不对称 | 左右大毛孔比例差异 | 反映左右两侧粗大毛孔负担是否存在明显偏重。 |
| 左右不对称 | 左右毛孔圆度差异 | 反映左右两侧典型毛孔圆度是否存在明显差异。 |
| 左右不对称 | 左右拉长毛孔比例差异 | 反映左右两侧拉长样毛孔负担是否存在差异。 |

# 五、可见毛孔评分组成

可见毛孔综合评分建议由以下指标组共同参与。

| **评分组成** | **建议初始权重** | **评分意义** |
| --- | --- | --- |
| 毛孔密度 | 20% | 反映单位皮肤面积内可见毛孔的数量负担。 |
| 毛孔面积占比 | 25% | 反映毛孔对皮肤表面的总体覆盖范围，综合受到毛孔数量和大小影响。 |
| 毛孔大小 | 25% | 主要参考P50毛孔面积和P90毛孔面积，反映典型毛孔及偏大毛孔的大小水平。 |
| 大毛孔比例 | 20% | 反映粗大毛孔在全部可见毛孔中的占比。 |
| 毛孔形态不规则度 | 10% | 主要反映低圆度、椭圆形及拉长样毛孔表现。 |

以上权重为第一版医学指导建议，后续可根据以下数据进行调整：

- 医学专家标注结果；

- 不同年龄段参考人群数据；

- 不同面部分区的正常范围；

- 重复拍摄稳定性结果；

- 治疗前后变化数据；

- 模型训练和验证结果。

# 六、分区评分与结果等级

## 6.1 分区评分

建议分别输出以下区域的毛孔评分：

- 额部毛孔评分；

- 鼻部毛孔评分；

- 左鼻旁毛孔评分；

- 右鼻旁毛孔评分；

- 左内侧面颊毛孔评分；

- 右内侧面颊毛孔评分；

- 左外侧面颊毛孔评分；

- 右外侧面颊毛孔评分；

- 下巴毛孔评分。

每个分区评分应综合反映：

- 毛孔密度；

- 毛孔面积占比；

- P50毛孔面积；

- P90毛孔面积；

- 大毛孔比例；

- 毛孔圆度；

- 拉长毛孔比例。

分区结果用于定位主要问题区域，不应只输出一个全面部总分。

## 6.2 结果等级

第一版可暂时采用以下图像学等级：

| **综合评分** | **等级** |
| --- | --- |
| 0～20分 | 未见明显 |
| 21～40分 | 轻度 |
| 41～60分 | 中度 |
| 61～80分 | 较明显 |
| 81～100分 | 显著 |

以上等级属于图像学分级，不代表疾病严重程度。

具体分界值后续应根据以下数据进行重新标定：

- 医学专家视觉评分；

- 参考人群分布；

- 不同年龄和肤质人群数据；

- 系统实际检测表现。

# 七、最终报告内容与示例

## 7.1 一级结果

- 可见毛孔综合评分；

- 可见毛孔等级；

- 主要毛孔问题区域；

- 左右不对称情况。

## 7.2 二级结果

- 毛孔数量负担；

- 毛孔粗大负担；

- 毛孔面积负担；

- 毛孔形态表现；

- 毛孔视觉明显程度；

- 各面部分区评分。

## 7.3 核心指标

报告中建议展示以下核心指标：

- 单位面积毛孔密度；

- 毛孔面积占比；

- P50毛孔面积；

- P90毛孔面积；

- 大毛孔比例；

- 低圆度或拉长毛孔比例；

- 主要问题区域；

- 左右面颊差异。

## 7.4 可视化结果

建议在用户面部照片上显示：

- 全部可见毛孔标记；

- 大毛孔重点标记；

- 拉长毛孔标记；

- 毛孔密度分布图；

- 分区毛孔负担图；

- 左右差异提示。

可视化颜色仅用于区分不同程度，不应暗示组织学诊断。

## 7.5 面部毛孔报告示例

### 可见毛孔：68分，较明显

面部可见毛孔主要集中于鼻部、双侧鼻旁及内侧面颊。

鼻部单位面积毛孔密度较高，鼻旁和内侧面颊的毛孔面积占比较高。大毛孔较多，大毛孔比例为23%，提示除毛孔数量较多外，部分毛孔还存在明显粗大表现。

多数毛孔呈圆形或椭圆形，少量毛孔呈拉长样表现。右侧内侧面颊的毛孔面积占比和大毛孔比例略高于左侧，外侧面颊毛孔负担相对较轻。

综合表现提示较明显的可见毛孔问题，以鼻部毛孔密集和内侧面颊毛孔粗大为主要表现。

# 八、医学说明、检测局限性与最终医学逻辑

## 8.1 医学说明与检测局限性

面部毛孔检测结果反映标准化照片中可见毛孔的：

- 数量；

- 大小；

- 面积；

- 圆度和长宽比；

- 对比度；

- 分布；

- 左右差异。

本报告不能直接判断：

- 毛孔是否被皮脂或角栓堵塞；

- 毛孔内部是否存在微粉刺；

- 毛孔真实深度；

- 皮脂腺体积；

- 皮脂分泌速度；

- 痤疮切割杆菌数量；

- 毛孔粗大是由皮脂、老化、松弛、瘢痕还是其他原因引起。

毛孔检测结果还可能受到以下因素影响：

- 图像分辨率；

- 拍摄焦距和距离；

- 光照方向；

- 面部角度；

- 图像清晰度；

- 毛发和胡须；

- 底妆和遮瑕；

- 护肤品残留；

- 局部高光或阴影。

因此，治疗前后或不同时间检测时，应尽量保持相同的拍摄设备、光照、距离、角度及面部清洁状态。

## 8.2 最终医学逻辑
