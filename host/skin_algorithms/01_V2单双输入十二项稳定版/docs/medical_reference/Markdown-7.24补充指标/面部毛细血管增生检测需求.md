# **面部毛细血管增生检测需求**

# 一、系统目标

通过VISIA红色区、标准白光图像及必要的多角度面部照片，识别面部红色线状、分支状、网状或放射状结构，评价浅表线状血管样结构的数量、长度、密度、宽度、红色强度、网络形态及分布，形成独立的面部毛细血管增生检测报告。

本报告主要评价：

**标准化图像中可见的线状血管扩张样红色结构，以及这些结构对面部红色外观造成的视觉影响。**

最终报告应回答以下问题：

- 面部可见线状血管样结构是否较多；

- 线状血管样结构的总体长度和覆盖范围有多大；

- 线状结构是否较宽或红色较明显；

- 是否形成分支状、网状或放射状结构；

- 主要集中于鼻翼、鼻旁、面颊、颧部或其他区域；

- 标准白光与VISIA红色区是否共同支持主要目标；

- 不同角度照片中主要线状结构是否稳定存在；

- 左右两侧是否存在明显差异。

本报告不直接评价：

- 真实血管数量；

- 组织学意义上的毛细血管增生；

- 真实血管直径；

- 血流速度；

- 血管壁状态；

- 血管反应性；

- 玫瑰痤疮、蜘蛛痣或其他血管性疾病的临床诊断。

# 二、医学定义

## 2.1 线状血管扩张样表型

本报告中的“毛细血管增生”在图像层面具体指：

**标准化面部图像中呈红色线状、分支状、网状或放射状分布，并在白光图像或VISIA红色区中能够重复识别的浅表血管样结构。**

文档名称使用“毛细血管增生”，但系统实际检测的是线状血管扩张样图像表型，不能仅根据图像证明血管数量真实增加或血管组织发生增生。

## 2.2 主要检测图层

本项目主要使用以下图像信息：

- VISIA红色区中的线状红色结构；

- 标准白光图像中的肉眼可见线状红色结构；

- 可见红色色差图层中的线状红色成分；

- 不同角度照片中的重复出现情况；

- 弥漫性背景泛红结果，用于校正线状结构周围的背景红色。

VISIA紫质、毛孔位置及局部隆起不作为本报告的主要评分依据。

# 三、主要检测区域

建议对以下面部区域分别检测：

- 鼻翼及鼻旁；

- 左面颊；

- 右面颊；

- 左颧部；

- 右颧部；

- 额部；

- 左眼周；

- 右眼周；

- 左下颌；

- 右下颌。

其中重点报告区域包括：

- 鼻翼及鼻旁；

- 双侧面颊；

- 双侧颧部。

## 3.1 分区检测的医学意义

分区检测可以用于：

- 判断线状血管样结构主要集中在哪些区域；

- 区分鼻翼局限性线状结构与面颊广泛性血管样网络；

- 比较不同区域的线长度密度、面积占比和红色强度；

- 比较左右面颊及颧部的血管样结构差异；

- 评价治疗或护理前后主要区域的变化。

不同分区面积不同，因此跨区域比较时，应优先使用线长度密度、面积占比和分支点密度，而不是只比较绝对数量或总长度。

# 四、需要检测的指标及医学意义

| **指标项目** | **需要检测的具体指标** | **医学意义** |
| --- | --- | --- |
| 目标数量 | 分区线状血管样目标数量 | 反映各面部分区内可识别的独立线状红色结构数量。 |
| 目标数量 | 全面部线状血管样目标总数 | 反映全面部可见线状血管样目标的总体数量负担。 |
| 长度负担 | 单条线状结构长度 | 反映每条线状血管样结构的延伸范围。 |
| 长度负担 | 分区线状结构总长度 | 反映某一分区内全部线状血管样结构的总体长度负担。 |
| 长度负担 | 全面部线状结构总长度 | 反映全面部线状血管样结构的总长度。 |
| 长度负担 | 线长度密度 | 反映单位有效皮肤面积内线状结构的总长度，便于不同区域之间比较。 |
| 面积负担 | 线状结构总面积 | 反映全部线状血管样结构的总体覆盖范围。 |
| 面积负担 | 线状结构面积占比 | 反映线状结构面积占有效皮肤面积的比例。 |
| 结构宽度 | P50线状结构宽度 | 反映典型线状血管样结构的宽度水平。 |
| 结构宽度 | P90线状结构宽度 | 反映较宽一组线状结构的宽度水平。 |
| 红色强度 | P50红色强度 | 反映典型线状结构的红色明显程度。 |
| 红色强度 | P90红色强度 | 反映较明显一组线状结构的红色程度。 |
| 分支与网络形态 | 分支点数量 | 反映线状血管样结构形成分支连接的数量。 |
| 分支与网络形态 | 分支点密度 | 反映单位有效皮肤面积内分支点的集中程度。 |
| 分支与网络形态 | 曲折度 | 反映线状结构弯曲和迂曲的程度。 |
| 分支与网络形态 | 网状结构比例 | 反映线状结构中形成相互连接网络的比例。 |
| 分支与网络形态 | 放射状结构数量 | 反映是否存在从局部中心向外放射的线状结构。 |
| 分支与网络形态 | 最大连续网络长度 | 反映单个最大连续血管样网络的延伸范围。 |
| 图像一致性 | 白光与VISIA红色区重叠率 | 反映两种成像结果是否共同支持主要线状结构。 |
| 图像一致性 | 多角度一致性 | 反映主要线状结构是否在不同角度照片中稳定出现，可用于降低阴影和噪声误判。 |
| 分区分布 | 各分区线长度密度 | 反映不同面部分区线状血管样结构的长度负担差异。 |
| 分区分布 | 各分区线状结构面积占比 | 反映不同区域的血管样结构覆盖范围。 |
| 分区分布 | 主要受累区域 | 用于判断线状血管样结构主要集中于鼻翼、鼻旁、面颊、颧部或其他区域。 |
| 左右不对称 | 左右面颊线长度密度差异 | 反映左右面颊线状血管样结构负担是否一致。 |
| 左右不对称 | 左右颧部面积占比差异 | 反映左右颧部血管样结构覆盖范围是否存在差异。 |
| 左右不对称 | 左右P90红色强度差异 | 反映左右两侧较明显线状结构的红色程度是否存在偏重。 |

# 五、毛细血管增生样评分组成

线状血管扩张样综合评分建议由以下指标组共同参与。

| **评分组成** | **建议初始权重** | **评分意义** |
| --- | --- | --- |
| 总长度、密度及面积 | 30% | 综合评价线状血管样结构的总体数量和覆盖负担。 |
| 红色强度及宽度 | 20% | 评价线状结构的红色明显程度和宽度水平。 |
| 分支、网状及曲折形态 | 20% | 评价线状结构是否形成复杂分支、网状连接或明显曲折。 |
| 白光与VISIA一致性 | 20% | 评价主要目标是否由两种图像共同支持，降低单一图层误判。 |
| 分区及左右差异 | 10% | 评价主要受累区域及左右不对称表现。 |

以上权重为第一版医学指导建议，后续可根据以下数据进行调整：

- 医学专家视觉标注；

- 白光与VISIA重复检测结果；

- 不同年龄和肤色人群参考数据；

- 治疗前后变化数据；

- 模型训练和验证结果。

# 六、分区评分与结果等级

## 6.1 分区评分

建议分别输出以下区域的线状血管扩张样评分：

- 鼻翼及鼻旁评分；

- 左面颊评分；

- 右面颊评分；

- 左颧部评分；

- 右颧部评分；

- 额部评分；

- 左眼周评分；

- 右眼周评分；

- 左下颌评分；

- 右下颌评分。

每个分区评分应综合反映线长度密度、面积占比、P90宽度、P90红色强度、分支或网状结构比例及图像一致性。

分区结果用于定位主要问题区域，不应只输出一个全面部总分。

## 6.2 结果等级

| **综合评分** | **等级** |
| --- | --- |
| 0～20分 | 未见明显 |
| 21～40分 | 轻度 |
| 41～60分 | 中度 |
| 61～80分 | 较明显 |
| 81～100分 | 显著 |

以上等级属于线状血管扩张样图像表型分级，不代表血管性疾病严重程度。具体分界值后续应根据医学专家标注、参考人群分布及系统实际检测表现重新标定。

# 七、最终报告内容与示例

## 7.1 一级结果

- 线状血管扩张样综合评分；

- 结果等级；

- 主要受累区域；

- 主要结构形态；

- 白光与VISIA一致性；

- 左右不对称情况。

## 7.2 二级结果

- 线状结构数量负担；

- 线状结构长度负担；

- 线状结构面积负担；

- 红色强度及宽度表现；

- 分支、网状及曲折形态；

- 多角度稳定性；

- 各面部分区评分。

## 7.3 核心指标

报告中建议展示以下核心指标：

- 线状结构总长度；

- 线长度密度；

- 线状结构面积占比；

- P90宽度；

- P90红色强度；

- 分支或网状结构比例；

- 白光与VISIA重叠率；

- 主要受累区域；

- 左右差异。

## 7.4 可视化结果

- 全部线状血管样结构标记；

- 分支点及网状连接标记；

- 高强度线状结构重点标记；

- 线长度密度分布图；

- 分区负担图；

- 左右差异提示。

可视化用于展示图像目标，不应将线状红色结构直接标注为确诊的毛细血管病变。

## 7.5 报告示例

### 血管样结构明显度评分：63分，较明显

鼻翼两侧和双侧面颊为重点区域，左侧略高于右侧。

血管样结构总长度和线长度密度均偏高，其中约34%的血管样结构形成分支或小型网状连接。标准白光图像与VISIA红色区中的主要血管样结构具有较高一致性，多数主要目标在不同角度照片中均可重复识别。

综合表现提示较明显的血管样结构，以鼻翼和左侧面颊最明显，并伴轻度弥漫性背景泛红。

本结果不能单独诊断毛细血管扩张症、玫瑰痤疮、蜘蛛痣或其他血管性疾病。

### 分区结果示例

| **面部分区** | **评分** | **主要表现** |
| --- | --- | --- |
| 鼻翼及鼻旁 | 72分 | 线长度密度及分支结构比例偏高 |
| 左面颊 | 67分 | 血管样结构总长度和面积占比较高 |
| 右面颊 | 59分 | 中度血管样结构负担 |
| 左颧部 | 61分 | 可见较明显分支状结构 |
| 右颧部 | 54分 | 中度血管样结构 |
| 额部 | 31分 | 血管样结构较少 |
| 眼周 | 28分 | 负担较轻 |
| 下颌 | 24分 | 负担较轻 |

> **关键指标日常注释：** “血管样结构总长度”和“线长度密度”表示可见血管样纹路有多少、分布多密；“较宽血管样结构”和“较强红色程度”表示更明显部分的宽度与红度；“分支或网状比例”表示这些纹路是否形成小分叉或小网状。分数适合用于观察同条件下的变化趋势。

# 八、医学说明、检测局限性与最终医学逻辑

## 8.1 医学说明与检测局限性

面部毛细血管增生检测结果反映标准化图像中可见线状血管样结构的：

- 数量；

- 长度和密度；

- 面积和覆盖范围；

- 宽度；

- 红色强度；

- 分支、网状和曲折形态；

- 分区分布；

- 左右差异。

本报告不能直接判断：

- 真实血管数量是否增加；

- 血管真实直径；

- 血流速度；

- 血管壁状态；

- 血管反应性；

- 具体血管性疾病。

检测结果可能受到光照、阴影、肤色差异、妆容、红色印记、毛发、图像清晰度及面部角度影响。不同时间检测时，应尽量保持相同设备、光照、距离、角度和面部清洁状态。

## 8.2 最终医学逻辑

面部毛细血管增生报告是一个线状血管扩张样图像表型报告。

其核心评价内容为：

**面部可见线状血管样结构有多少、延伸多长、覆盖多广、红色有多明显、是否形成分支或网状结构，以及主要分布在哪里。**
