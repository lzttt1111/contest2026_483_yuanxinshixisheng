# **面部油脂分泌检测需求说明**

# 一、系统目标

通过标准化面部照片，结合皮肤表面油光表现和UV图像中的毛囊卟啉荧光信号，评价面部是否呈现与油脂分泌活跃相符的图像特征，形成独立的面部油脂分泌检测报告。

本报告主要评价：

**标准化拍摄条件下面部皮肤的表面油亮程度，以及毛囊内卟啉相关荧光信号所反映的油脂相关毛囊环境。**

最终报告应回答以下问题：

- 当前面部表面油光是否明显；

- 油光覆盖范围有多大；

- 是否存在大片连续性油光；

- 油光主要集中于T区还是扩展至面颊；

- 毛囊卟啉荧光目标是否较多；

- 毛囊卟啉荧光强度是否明显；

- 表面油光与毛囊卟啉表现是否一致；

- 油脂分泌活跃倾向主要集中在哪些面部区域；

- 左右两侧油脂相关表现是否存在差异。

本报告不直接评价：

- 皮脂仪测得的皮脂绝对含量；

- 单位时间内的皮脂分泌速率；

- 皮脂腺数量和体积；

- 痤疮切割杆菌的实际数量；

- 痤疮严重程度；

- 毛孔粗大程度；

- 毛孔堵塞程度；

- 油性皮肤的医学诊断。

# 二、医学定义

本报告中的“油脂分泌倾向”是指：

**在标准化拍摄条件下，由皮肤表面油亮反光和毛囊卟啉荧光共同呈现出的油脂相关图像表型。**

油脂分泌倾向由两个相互补充的图像表现组成。

## 2.1 表面油光表现

表面油光是指皮肤表面因镜面反射形成的局部或连续性高亮区域。

表面油光更接近当前拍摄时皮肤表面的油亮外观，但同时可能受到以下因素影响：

- 汗液；

- 护肤品；

- 防晒产品；

- 底妆；

- 表面水膜；

- 拍摄光源；

- 拍摄角度；

- 清洁后经过的时间。

因此，表面油光不能单独等同于皮脂分泌量。

## 2.2 毛囊卟啉表现

毛囊卟啉是指UV图像中呈现于毛囊位置的橙红色或红色荧光信号。

毛囊卟啉与痤疮切割杆菌的卟啉代谢及毛囊皮脂环境存在一定关系，可作为油脂相关毛囊活跃程度的间接图像指标。

毛囊卟啉同时可能受到以下因素影响：

- 毛囊内微生物数量；

- 菌株及其产卟啉能力；

- 毛囊堵塞情况；

- 面部清洁状态；

- 抗菌药物；

- 维A酸类产品；

- 过氧化苯甲酰；

- 化妆品或护肤品残留；

- UV拍摄参数。

因此，毛囊卟啉不能直接换算为皮脂量或细菌数量。

# 三、主要检测区域

建议对以下面部区域分别检测：

- 额部；

- 鼻部；

- 左鼻旁；

- 右鼻旁；

- 左内侧面颊；

- 右内侧面颊；

- 左外侧面颊；

- 右外侧面颊；

- 下巴。

同时可将相关区域组合为以下两个主要范围。

## 3.1 T区

包括：

- 额部中央；

- 鼻部；

- 下巴。

T区通常作为表面油光和毛囊卟啉表现的重点检测区域。

## 3.2 面颊区

包括：

- 鼻旁；

- 内侧面颊；

- 外侧面颊。

面颊区检测用于判断油脂相关表现是否由中央面部向外扩展。

## 3.3 分区检测的医学意义

分区检测可以用于：

- 判断油脂相关表现主要集中在哪些区域；

- 区分T区集中型和广泛分布型油光；

- 比较鼻部、鼻旁和面颊的卟啉负担；

- 比较表面油光与毛囊卟啉的空间一致性；

- 比较左右面颊的油脂相关表现；

- 评价治疗或护理前后不同区域的变化。

不同分区面积不同，因此跨区域比较时，应优先使用面积占比、单位面积密度及强度水平，而不是只比较绝对数量或总面积。

# 五、油脂分泌倾向评分组成

油脂分泌倾向综合评分建议由表面油光表现和毛囊卟啉表现共同参与。

| **评分组成** | **建议初始权重** | **评分意义** |
| --- | --- | --- |
| 表面油光表现 | 60% | 反映当前标准化拍摄条件下皮肤表面的油亮范围、强度及分布。 |
| 毛囊卟啉表现 | 40% | 反映毛囊内卟啉相关荧光信号的数量、面积、强度及分布，为油脂相关毛囊环境提供辅助依据。 |

上述权重属于第一版医学指导建议，后续可根据以下数据进行调整：

- 直接皮脂测量结果；

- 医学专家视觉评分；

- 标准化拍摄下的重复检测结果；

- 不同年龄和肤质人群参考数据；

- 治疗或护理前后变化数据；

- 模型训练和验证结果。

## 5.1 表面油光评分组成

| **评分组成** | **建议初始权重** | **评分意义** |
| --- | --- | --- |
| 油光面积占比 | 35% | 反映油光覆盖皮肤表面的范围。 |
| 油光强度 | 25% | 反映典型油光及较明显油光区域的强度水平。 |
| 高强度油光负担 | 15% | 反映明显油亮区域的数量和面积贡献。 |
| 最大连续油光区域 | 10% | 反映是否形成大片连续性油亮表现。 |
| 油光分布范围 | 15% | 反映油光主要集中于T区、扩展至面颊或呈广泛分布。 |

# 八、医学说明、检测局限性与最终医学逻辑

## 8.1 医学说明与检测局限性

面部油脂分泌检测结果反映标准化照片中的：

- 表面油光面积；

- 表面油光强度；

- 油光分布；

- 毛囊卟啉数量；

- 毛囊卟啉面积；

- 毛囊卟啉荧光强度；

- 高强度卟啉负担；

- 分区分布；

- 左右差异。

本报告不能直接判断：

- 实际皮脂分泌量；

- 单位时间皮脂分泌速度；

- 皮脂腺数量或体积；

- 毛囊内微生物的实际数量；

- 毛囊是否堵塞；

- 是否存在微粉刺；

- 痤疮是否处于活动期；

- 是否属于医学诊断意义上的油性皮肤。

表面油光结果可能受到以下因素影响：

- 汗液；

- 护肤品；

- 防晒产品；

- 底妆；

- 面部清洁状态；

- 清洁或涂抹产品后经过的时间；

- 环境温度和湿度；

- 拍摄光源；

- 相机曝光；

- 拍摄角度；

- 面部曲面结构。

毛囊卟啉结果可能受到以下因素影响：

- 痤疮切割杆菌数量和菌株差异；

- 细菌产卟啉能力；

- 毛囊局部环境；

- 面部清洁状态；

- 抗菌药物；

- 维A酸类产品；

- 过氧化苯甲酰；

- 护肤品或化妆品残留；

- UV光源及拍摄参数。

治疗前后或不同时间检测时，应尽量保持以下条件一致：

- 拍摄设备；

- 光源位置和亮度；

- 相机曝光；

- 拍摄距离和角度；

- 面部清洁状态；

- 检测前护肤品和化妆品使用情况；

- 清洁后等待时间；

- 检测环境温度和湿度。

## 8.2 最终医学逻辑

面部油脂分泌报告是一个基于图像的油脂相关表型报告。

其核心评价内容为：

**当前面部皮肤表面有多油亮，毛囊卟啉荧光有多明显，两种表现是否一致，以及油脂相关表现主要分布在哪里。**

表面油光用于描述当前皮肤表面的油亮外观，毛囊卟啉用于描述毛囊内卟啉相关代谢信号。

两者共同形成油脂分泌倾向评价，但不能替代皮脂仪等设备对实际皮脂分泌量和皮脂分泌速率的直接测量。
