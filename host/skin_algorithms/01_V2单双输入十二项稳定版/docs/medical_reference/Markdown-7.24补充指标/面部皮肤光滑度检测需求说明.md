# **面部皮肤光滑度检测需求说明**

# 一、系统目标

系统通过用户的标准化面部照片及照片重建的3D人脸模型，评价面部皮肤光滑程度。

本检测重点识别以下三类表面不平整：

1. **隆起性不平整；**

1. **凹陷性不平整；**

1. **表面附着物性不平整。**

在三个分项结果的基础上，形成面部皮肤光滑度综合结果。

本检测不包括：

- 皱纹及干燥样细纹；

- 毛孔；

- 法令纹、木偶纹、泪沟、颊中沟等结构性沟槽；

- 单纯色斑、红斑及肤色不均；

- 仅在极高分辨率照片下才能稳定识别的细碎粗糙纹理。

最终报告应输出：

- 面部皮肤光滑度分数及等级；

- 隆起性不平整评分；

- 凹陷性不平整评分；

- 表面附着物性不平整评分；

- 各面部分区结果；

- 左右差异；

- 主要问题类型和主要受累区域；

- 医学解释及检测局限性。

# 二、医学定义

## 2.1 面部皮肤光滑度

面部皮肤光滑度是指：排除皱纹、毛孔、大尺度结构性沟槽和单纯颜色异常后，面部皮肤因局部隆起、局部凹陷及表面附着物所呈现的视觉光滑程度。

面部皮肤光滑度分数越高，表示皮肤越光滑；分数越低，表示局部隆起、凹陷或表面附着物造成的光滑度下降越明显。

本系统评价的是照片和3D模型中的表面外观，不直接诊断具体皮肤疾病。

## 2.2 隆起性不平整

隆起性不平整是指局部皮肤表面高于周围皮肤形成的凸起性外观。

可能包括：

- 肤色丘疹样隆起；

- 闭口样隆起；

- 白色或淡黄色颗粒样隆起；

- 红色丘疹样隆起；

- 脓疱样隆起；

- 局部瘢痕样隆起；

- 其他非正常解剖结构性凸起。

报告中统一称为“隆起性不平整”，不直接诊断为：

- 痤疮；

- 闭合性粉刺；

- 粟丘疹；

- 毛囊炎；

- 增生性瘢痕。

## 2.3 凹陷性不平整

凹陷性不平整是指局部皮肤表面低于周围皮肤形成的凹陷。

本项目不包括：

- 正常毛孔；

- 皱纹及细纹；

- 法令纹、木偶纹等结构性沟槽；

- 正常面部解剖凹陷。

可能包括：

- 痘坑样凹陷；

- 萎缩性瘢痕样凹陷；

- 点状凹陷；

- 边界较清楚的局部凹陷；

- 浅波浪状凹陷；

- 其他局部瘢痕样凹陷。

报告中统一称为“凹陷性不平整”，不直接诊断具体痤疮瘢痕类型。

## 2.4 表面附着物性不平整

表面附着物性不平整是指附着、堆积或翘起于皮肤表面的物质造成的局部不平整。

可能包括：

- 白色细碎皮屑；

- 片状脱屑；

- 翘起角质；

- 鳞屑样附着；

- 痂皮样附着；

- 其他可见表面附着物。

该项目容易受到妆容、防晒、护肤品残留和光照反射影响，因此作为辅助评价项目。

# 三、检测区域

建议分别检测以下面部分区：

- 额部；

- 鼻部；

- 左鼻旁；

- 右鼻旁；

- 左颧部；

- 右颧部；

- 左面颊；

- 右面颊；

- 口周；

- 左下颌部；

- 右下颌部。

不同检测目标的重点区域如下：

| **检测目标** | **重点检测区域** |
| --- | --- |
| 隆起性不平整 | 额部、鼻旁、面颊、口周、下颌部 |
| 凹陷性不平整 | 颧部、面颊及其他局部瘢痕样区域 |
| 表面附着物性不平整 | 鼻旁、眉间、口周、面颊及下颌部 |

左右对称区域应分别检测，以评价左右分布差异。

以下区域不作为有效皮肤检测区域：

- 眉毛及睫毛；

- 头发遮挡区域；

- 眼睑边缘；

- 鼻孔；

- 唇红；

- 耳部边缘；

- 明显遮挡区域；

- 严重反光区域；

- 无法可靠判断表面形态的模糊区域。

# 四、隆起性不平整

## 4.1 测量目标

系统应识别面部皮肤表面独立或成群分布的局部隆起目标，并测量其数量、大小、高度、体积、形态、颜色及分布。

每个隆起目标应至少明确：

- 所属面部分区；

- 中心位置；

- 目标面积；

- 相对高度；

- 隆起体积；

- 形态特征；

- 边界特征；

- 颜色类型；

- 是否呈聚集分布；

- 检测可信度。

## 4.2 检测指标及临床含义

| **检测指标** | **临床含义** |
| --- | --- |
| 隆起目标数量 | 反映局部凸起目标的数量负担 |
| 隆起目标密度 | 反映单位皮肤面积内隆起目标的密集程度 |
| 隆起总面积 | 反映全部隆起目标影响的总体范围 |
| 隆起面积占比 | 反映分区皮肤中受到隆起影响的比例 |
| P50面积 | 反映典型隆起目标的面积水平 |
| P90面积 | 反映较大隆起目标的面积水平 |
| 平均相对高度 | 反映隆起目标整体高于周围皮肤的程度 |
| 最大相对高度 | 反映最明显隆起目标的高度水平 |
| P90相对高度 | 反映较高一组隆起目标的高度水平 |
| 隆起总体积 | 综合反映隆起目标的面积和高度负担 |
| 单位面积隆起体积 | 反映不同分区内隆起体积的集中程度 |
| 圆度及长宽比 | 描述隆起目标是否呈规则圆形或不规则形态 |
| 边界清晰度 | 反映隆起与周围皮肤的分界程度 |
| 聚集程度 | 反映隆起目标是散在分布还是局部成群 |
| 颜色类型 | 描述隆起以肤色、白色、黄色或红色外观为主 |
| 主要分布区域 | 明确隆起性问题主要集中于哪些面部分区 |
| 左右差异 | 反映左右对应区域的隆起负担是否存在差异 |

隆起性不平整不能只根据目标数量判断。

例如：

- 数量较多但面积和高度均较小，可能表现为密集细小隆起；

- 数量较少但高度或体积较大，也可能明显影响皮肤光滑度；

- 隆起集中成片时，其视觉影响可能高于相同数量的散在隆起。

因此，应综合数量、密度、面积、高度、体积及分布情况评价。

## 4.3 评分组成

隆起性不平整评分建议由以下指标组组成：

| **指标组** | **初始权重** | **评分用途** |
| --- | --- | --- |
| 隆起面积占比 | 25% | 评价隆起目标影响皮肤表面的总体范围 |
| 隆起目标密度 | 20% | 评价单位面积内隆起目标的数量负担 |
| 隆起相对高度 | 20% | 评价隆起高于周围皮肤的程度 |
| 隆起总体积 | 20% | 综合评价隆起目标的面积和高度 |
| 较大或较高隆起负担 | 10% | 评价较明显隆起目标对结果的贡献 |
| 聚集及分布情况 | 5% | 评价隆起是否集中或呈成群分布 |

隆起性不平整分数越高，表示局部凸起目标对皮肤光滑度的影响越明显。

颜色类型主要用于报告描述和表型区分，不建议作为光滑度下降程度的主要评分因素。

## 4.4 报告内容

隆起性不平整报告应包括：

- 隆起性不平整总分及程度；

- 主要受累区域；

- 隆起目标数量和密度；

- 隆起面积占比；

- 平均相对高度；

- 较高隆起目标负担；

- 隆起总体积；

- 主要颜色类型；

- 是否呈局部聚集；

- 左右差异；

- 医学解释。

# 五、凹陷性不平整

## 5.1 测量目标

系统应识别除毛孔、皱纹和结构性沟槽以外的局部凹陷目标，并测量其数量、面积、深度、体积、边缘形态和分布。

每个凹陷目标应至少明确：

- 所属面部分区；

- 中心位置；

- 目标面积；

- 相对深度；

- 凹陷体积；

- 边缘坡度；

- 边界清晰度；

- 凹陷形态；

- 是否呈聚集分布；

- 检测可信度。

## 5.2 检测指标及临床含义

| **检测指标** | **临床含义** |
| --- | --- |
| 凹陷目标数量 | 反映局部凹陷目标的数量负担 |
| 凹陷目标密度 | 反映单位皮肤面积内凹陷目标的集中程度 |
| 凹陷总面积 | 反映全部凹陷目标影响的总体范围 |
| 凹陷面积占比 | 反映分区皮肤中受到凹陷影响的比例 |
| P50面积 | 反映典型凹陷目标的面积水平 |
| P90面积 | 反映较大凹陷目标的面积水平 |
| 平均相对深度 | 反映凹陷目标整体低于周围皮肤的程度 |
| 最大相对深度 | 反映最明显凹陷目标的深度水平 |
| P90相对深度 | 反映较深一组凹陷目标的深度水平 |
| 凹陷总体积 | 综合反映凹陷目标的面积和深度负担 |
| 单位面积凹陷体积 | 反映不同分区内凹陷体积的集中程度 |
| 边缘坡度 | 反映凹陷与周围皮肤之间的过渡是否陡峭 |
| 边界清晰度 | 反映凹陷轮廓是否明确 |
| 凹陷形态 | 描述点状、边界清楚、浅波浪状或混合外观 |
| 聚集程度 | 反映凹陷是散在分布还是集中于局部区域 |
| 主要分布区域 | 明确凹陷性问题主要集中于哪些区域 |
| 左右差异 | 反映双侧凹陷面积、深度和体积是否存在差异 |

凹陷性不平整应重点结合面积、深度和体积评价。

例如：

- 小面积但深度较大的凹陷，可能表现为点状深凹；

- 面积较大但深度较浅的凹陷，可能表现为浅波浪状表面不均；

- 数量较少但总体积较大的凹陷，也可能明显影响皮肤光滑度。

凹陷目标必须与以下目标区分：

- 毛孔；

- 皱纹；

- 干燥样细纹；

- 法令纹；

- 木偶纹；

- 泪沟；

- 颊中沟；

- 正常解剖凹陷。

## 5.3 评分组成

凹陷性不平整评分建议由以下指标组组成：

| **指标组** | **初始权重** | **评分用途** |
| --- | --- | --- |
| 凹陷面积占比 | 20% | 评价凹陷目标影响皮肤表面的总体范围 |
| 凹陷目标密度 | 15% | 评价单位面积内凹陷目标的数量负担 |
| 凹陷相对深度 | 25% | 评价凹陷低于周围皮肤的程度 |
| 凹陷总体积 | 25% | 综合评价凹陷目标的面积和深度 |
| 边缘坡度及形态 | 10% | 评价凹陷边缘及整体外观的明显程度 |
| 聚集及分布情况 | 5% | 评价凹陷是否集中于局部区域及左右分布差异 |

凹陷性不平整分数越高，表示非毛孔、非皱纹性局部凹陷对皮肤光滑度的影响越明显。

凹陷深度和体积的重要性应高于单纯数量，避免将大量浅小凹陷与少量明显深凹视为相同程度。

## 5.4 报告内容

凹陷性不平整报告应包括：

- 凹陷性不平整总分及程度；

- 主要受累区域；

- 凹陷目标数量和密度；

- 凹陷面积占比；

- 平均及最大相对深度；

- 较深凹陷目标负担；

- 凹陷总体积；

- 主要凹陷形态；

- 聚集程度；

- 左右差异；

- 医学解释。

# 六、表面附着物性不平整

## 6.1 测量目标

系统应识别附着、堆积或翘起于皮肤表面的异常区域，并描述其数量、面积、形态、分布及检测可信度。

每个附着物区域应至少明确：

- 所属面部分区；

- 区域面积；

- 细碎或片状类型；

- 边缘是否翘起；

- 是否呈聚集分布；

- 是否与红色区域重叠；

- 检测可信度。

## 6.2 检测指标及临床含义

| **检测指标** | **临床含义** |
| --- | --- |
| 附着物区域数量 | 反映皮屑、角质或其他附着物分布的离散程度 |
| 附着物总面积 | 反映全部附着物覆盖皮肤的总体范围 |
| 附着物面积占比 | 反映分区皮肤中受到附着物影响的比例 |
| P50区域面积 | 反映典型附着物区域的大小 |
| P90区域面积 | 反映较大片状附着物的面积水平 |
| 细碎或片状类型 | 描述附着物以粉屑样、细碎样还是片状为主 |
| 边缘形态 | 反映是否存在明显翘起或不规则边缘 |
| 聚集程度 | 反映附着物是散在分布还是局部成片 |
| 与红色区域重叠率 | 描述附着物区域是否同时伴有明显红色信号 |
| 主要分布区域 | 明确附着物主要位于哪些面部分区 |
| 检测可信度 | 评价结果是否可能受到妆容、护肤品、防晒或反光影响 |

表面附着物性不平整主要反映皮屑、角质翘起或其他表面附着物造成的视觉不平整。

该项目容易受到以下因素干扰：

- 粉底或遮瑕；

- 防晒及护肤品残留；

- 卡粉；

- 油光及高光；

- 图像压缩；

- 曝光变化。

因此，其医学解释应比隆起性和凹陷性结果更加谨慎。

## 6.3 评分组成

表面附着物性不平整评分建议由以下指标组组成：

| **指标组** | **初始权重** | **评分用途** |
| --- | --- | --- |
| 附着物面积占比 | 40% | 评价附着物影响皮肤表面的总体范围 |
| 附着物区域数量 | 20% | 评价附着物分布的数量负担 |
| 片状或翘起形态 | 20% | 评价附着物对皮肤光滑度的实际影响 |
| 聚集程度 | 10% | 评价附着物是否局部成片 |
| 与红色区域重叠 | 10% | 描述附着物是否伴有红色图像信号 |

表面附着物性不平整作为辅助评价项目，仅在检测可信度达到要求时参与综合评价。

检测可信度不足时，应：

- 保留检测结果作为提示；

- 标明可能存在妆容或护肤品干扰；

- 不将该项作为面部皮肤光滑度的重要依据。

## 6.4 报告内容

表面附着物性不平整报告应包括：

- 表面附着物性不平整总分及程度；

- 主要分布区域；

- 附着物区域数量；

- 总面积及面积占比；

- 主要表现为细碎型还是片状型；

- 是否存在明显翘起边缘；

- 是否伴有红色信号；

- 检测可信度；

- 医学解释和干扰因素说明。

# 七、综合面部皮肤光滑度

## 7.1 综合评价组成

面部皮肤光滑度由以下三个分项共同决定：

| **检测项目** | **初始综合权重** |
| --- | --- |
| 隆起性不平整 | 45% |
| 凹陷性不平整 | 50% |
| 表面附着物性不平整 | 5% |

其中：

- 凹陷性不平整权重略高，主要考虑凹陷深度和体积对皮肤光滑度的持续影响；

- 隆起性不平整是综合评价的重要组成；

- 表面附着物容易受到拍摄条件、妆容及护肤品影响，因此作为低权重辅助项目。

表面附着物检测可信度不足时，该项目不参与综合评价，最终结果主要由隆起性不平整和凹陷性不平整决定。

以上权重属于第一版医学建议，后续可根据医学专家标注和训练数据进行调整。

## 7.2 综合结果表达

用户报告只输出：

- 面部皮肤光滑度分数；

- 面部皮肤光滑度等级；

- 主要影响类型；

- 主要受累区域；

- 左右差异；

- 主要贡献指标；

- 检测可信度。

面部皮肤光滑度分数越高，表示皮肤越光滑；分数越低，表示隆起、凹陷或表面附着物造成的光滑度下降越明显。

# 八、面部皮肤光滑度等级建议

| **面部皮肤光滑度分数** | **结果** |
| --- | --- |
| 81～100 | 皮肤较光滑 |
| 61～80 | 轻度光滑度下降 |
| 41～60 | 中度光滑度下降 |
| 21～40 | 较明显光滑度下降 |
| 0～20 | 显著光滑度下降 |

以上等级属于第一版参考标准，后续应根据医学专家标注和参考人群数据重新校准。

隆起性不平整、凹陷性不平整及表面附着物性不平整可以分别输出分数和程度，用于解释面部皮肤光滑度下降的主要原因。

# 九、最终报告内容

## 9.1 综合结果

最终报告应输出：

- 面部皮肤光滑度总分；

- 面部皮肤光滑度等级；

- 主要问题类型；

- 主要受累区域；

- 左右差异；

- 检测可信度。

## 9.2 分项结果

分别输出：

- 隆起性不平整评分及程度；

- 凹陷性不平整评分及程度；

- 表面附着物性不平整评分及程度；

- 各面部分区结果；

- 各类型的主要贡献指标。

## 9.3 主要贡献指标

每个检测项目显示3～5项核心指标。

隆起性不平整建议显示：

- 隆起目标密度；

- 隆起面积占比；

- 平均相对高度；

- 隆起总体积；

- 主要聚集区域。

凹陷性不平整建议显示：

- 凹陷面积占比；

- 平均相对深度；

- 最大相对深度；

- 凹陷总体积；

- 左右差异。

表面附着物性不平整建议显示：

- 附着物面积占比；

- 主要形态；

- 主要分布区域；

- 与红色区域重叠情况；

- 检测可信度。

## 9.4 医学解释和检测限制

报告应明确：

- 结果反映照片及3D模型中的皮肤表面外观；

- 不直接诊断具体皮肤疾病；

- 不能根据隆起外观直接确诊痤疮、闭合性粉刺、粟丘疹或毛囊炎；

- 不能根据凹陷外观直接确诊具体瘢痕类型；

- 表面附着物结果可能受到妆容、护肤品、防晒和光照影响；

- 3D模型未达到真实物理尺度时，高度、深度和体积应作为相对指标解释。

# 十、报告示例

## 面部皮肤光滑度检测报告

### 1. 综合结果

面部皮肤光滑度：42分，表现为中度光滑度下降。

本次检测显示，影响面部皮肤光滑度的主要因素为：

1. 双侧面颊的凹陷性不平整；

2. 下颌部及鼻旁的隆起性不平整；

3. 表面附着物性改变较轻。

右侧面颊的凹陷性不平整程度高于左侧。

### 2. 隆起性不平整

评分：55分，中度。

下颌部及鼻旁为重点区域。

下颌部局部隆起目标数量、密度及面积占比较高，部分目标呈聚集分布；鼻旁可见一定数量的小型隆起。额部及双侧面颊的隆起性问题相对较轻。

检测到的隆起目标以肤色和红色隆起外观为主。

该结果反映局部凸起对皮肤光滑度的影响，不代表对痤疮、闭合性粉刺、粟丘疹、毛囊炎或其他疾病作出诊断。

### 3. 凹陷性不平整

评分：67分，较明显。

双侧面颊为重点区域，右侧重于左侧。

右侧面颊的凹陷面积占比、平均相对深度及凹陷总体积均高于左侧；双侧颧部可见中度局部凹陷，下颌部凹陷性改变较轻。

凹陷外观以局部边界较清楚型和浅波浪型为主。

该结果反映非毛孔、非皱纹性的局部凹陷外观，不代表对具体痤疮瘢痕类型作出诊断。

### 4. 表面附着物性不平整

评分：16分，未见明显。

鼻旁可见少量局部白色细碎附着物，但范围较小，对整体面部皮肤光滑度影响有限。

该结果可能受到护肤品、防晒、妆容及光线反射影响，应结合检测可信度谨慎解释。

### 5. 综合评价

本次面部皮肤光滑度为42分，主要受到双侧面颊凹陷性改变的影响，其次为下颌部及鼻旁的局部隆起性改变。

右侧面颊凹陷性不平整程度高于左侧，未见明显大面积表面附着物异常。

本报告反映面部照片及3D模型中的皮肤光滑外观，不用于诊断具体皮肤疾病。

### 6. 关键指标日常注释

| **关键指标** | **本例表现** | **居家理解** |
| --- | --- | --- |
| 局部小凸起数量和面积 | 下颌部、鼻旁较明显 | 表示能看到多少小凸起，以及它们影响了多大范围 |
| 局部凹陷范围和明显程度 | 双侧面颊较明显，右侧更高 | 表示皮肤表面有多少凹陷，以及凹陷看起来有多明显 |
| 表面细碎附着物 | 较轻 | 表示照片中可见的细小起屑、残留或反光区域 |
| 左右差异 | 右侧面颊较高 | 用于确定日常护理和复测时需要重点观察的一侧 |

> **关键指标日常注释：** 光滑度分数越高表示皮肤表面越平整。小凸起、局部凹陷和表面细碎附着物会分别从不同方向影响光滑感；清洁状态、护肤品残留、光线和拍摄角度都可能影响结果。

# 十一、医学解释边界

本报告可以表述：

- 局部隆起性目标较多；

- 隆起目标主要集中于下颌部；

- 双侧面颊存在较明显凹陷性不平整；

- 右侧凹陷深度和体积高于左侧；

- 表面附着物范围较小；

- 面部皮肤光滑度中度下降；

- 面部皮肤光滑度下降主要由凹陷性改变造成。

本报告不应直接表述：

- 检测到闭合性粉刺；

- 确诊痤疮；

- 确诊粟丘疹；

- 确诊毛囊炎；

- 确诊冰锥型、箱车型或滚动型瘢痕；

- 皮肤屏障受损；

- 皮肤含水量下降；

- 角质代谢异常；

- 某种具体疾病导致表面不平整。
