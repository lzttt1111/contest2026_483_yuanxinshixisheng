# **面部稳定性线性皱纹检测需求说明**

# 一、系统目标

系统通过用户的标准化正面、左右侧面照片及由照片重建的3D人脸模型，识别放松状态下持续可见、具有相对明确长度、方向和连续性的线状皱纹，形成独立的面部稳定性线性皱纹检测报告。

本报告主要评价：

**放松状态照片中可稳定识别的线状皱纹数量、长度、宽度、面积、视觉对比度、方向形态、多图稳定性及三维凹陷支持。**

最终报告应回答以下问题：

- 面部稳定性线性皱纹是否明显；

- 皱纹主要集中于额部、眉间、眼尾还是口周；

- 皱纹的数量、长度、宽度及面积负担是否较高；

- 纹路是否具有典型方向、连续性或放射状形态；

- 同一纹路在不同角度照片中是否稳定出现；

- 3D模型中是否存在对应的相对凹陷；

- 左右眼尾或其他对应区域是否存在差异。

本报告不直接评价：

- 表情状态下才出现的动态皱纹；

- 干燥性细纹形成的细碎交织纹理；

- 法令纹、木偶纹、颊中沟、泪沟等结构性沟槽；

- 胶原含量、弹力纤维状态或真皮组织学损伤；

- 皱纹的具体病因及组织学分型。

# 二、医学定义

## 2.1 稳定性线性皱纹

稳定性线性皱纹是指在面部放松状态的标准化照片中持续可见，具有相对明确长度、方向和连续性的线状纹路。其外观接近通常所说的静态皱纹或真性皱纹，但本报告仅评价图像表型。

稳定性线性皱纹通常具有以下特点：

- 位于相对典型的面部区域；

- 具有较明确的线状走向；

- 长度和连续性相对稳定；

- 在多张不同角度照片中可重复识别；

- 部分较明显皱纹可在3D模型中获得对应的相对凹陷支持。

## 2.2 与其他纹路表型的区别

| **纹路类型** | **主要区别** |
| --- | --- |
| 稳定性线性皱纹 | 以相对明确、较连续的线状纹路为主，常具有典型方向和多图稳定性。 |
| 干燥性细纹 | 以短、细、浅、密集和多方向交织的区域性细碎纹理为主。 |
| 结构性沟槽 | 以较宽、较长、较深的大尺度沟槽为主，并具有明显三维曲面变化。 |

三类纹路报告相互独立，不要求对每条候选纹路进行互斥分类。同一候选纹路可同时具有其他纹路表型，但本报告只评价其稳定性线性皱纹符合程度。

## 2.3 医学解释边界

稳定性线性皱纹评分反映照片和3D模型中的线状皱纹外观，不代表设备直接检测到胶原断裂、真皮纤维断裂或皮肤生物力学性能下降。

# 三、主要检测区域

建议对以下面部区域分别检测：

- 额部；

- 眉间；

- 左眼尾；

- 右眼尾；

- 口周。

## 3.1 各区域重点识别方向

| **检测区域** | **重点识别表现** |
| --- | --- |
| 额部 | 水平排列、相对平行的线性纹路。 |
| 眉间 | 垂直或斜向、相对集中的线性纹路。 |
| 左眼尾 | 以左侧外眼角为中心的放射状线性纹路。 |
| 右眼尾 | 以右侧外眼角为中心的放射状线性纹路。 |
| 口周 | 垂直、斜向或放射状分布的线性纹路。 |

## 3.2 分区检测的医学意义

- 判断稳定性线性皱纹主要集中在哪些区域；

- 区分额部水平纹、眉间垂直纹、眼尾放射纹和口周线性纹；

- 比较左右眼尾皱纹负担；

- 评价治疗或护理前后不同区域的变化。

## 3.3 无效或需谨慎检测区域

- 头发、眉毛或睫毛遮挡区域；

- 眼睑边缘、唇红及鼻孔；

- 明显表情牵拉区域；

- 严重高光、阴影或曝光异常区域；

- 图像模糊或无法稳定识别纹路形态的区域。

# 五、稳定性线性皱纹评分组成

稳定性线性皱纹综合评分建议由以下指标组共同参与：

| **评分组成** | **建议初始权重** | **评分意义** |
| --- | --- | --- |
| 常见部位匹配 | 20% | 评价候选纹路是否位于额部、眉间、眼尾或口周等典型区域，并符合相应方向。 |
| 线性形态 | 25% | 评价纹路长度、连续性、线性度、典型方向及放射性。 |
| 宽度和视觉强度 | 20% | 评价纹路宽度、面积、对比度及局部视觉明显程度。 |
| 多图稳定性 | 25% | 评价同一纹路在不同角度照片中是否持续存在并保持相近位置和形态。 |
| 三维凹陷支持 | 10% | 评价3D模型中是否存在与二维纹路相对应的相对凹陷。 |

以上权重为第一版医学指导建议，后续可根据医学专家标注、重复拍摄稳定性、治疗前后变化及模型训练结果进行调整。

# 六、分区评分与结果等级

## 6.1 分区评分

建议分别输出以下区域的稳定性线性皱纹评分：

- 额部评分；

- 眉间评分；

- 左眼尾评分；

- 右眼尾评分；

- 口周评分；

- 全面部稳定性线性皱纹评分。

每个分区评分应综合反映：

- 典型部位及方向匹配；

- 纹路数量和单位面积密度；

- 纹路总长度及P90长度；

- 纹路宽度和面积负担；

- 纹路视觉对比度；

- 连续性、线性度或放射性；

- 多图稳定性；

- 三维凹陷支持。

分区结果用于定位主要受累区域，不应只输出一个全面部总分。

## 6.2 结果等级

第一版可暂时采用以下图像学等级：

| **综合评分** | **等级** |
| --- | --- |
| 0～20分 | 未见明显 |
| 21～40分 | 轻度 |
| 41～60分 | 中度 |
| 61～80分 | 较明显 |
| 81～100分 | 显著 |

以上等级属于基于照片及3D模型的稳定性线性皱纹图像学分级，不代表组织学损伤程度或具体疾病严重程度。

具体分界值后续应根据以下数据进行重新标定：

- 医学专家视觉评分；

- 参考人群分布；

- 不同年龄及肤质人群数据；

- 标准化重复拍摄结果；

- 系统实际检测表现。

- 多图稳定性；

- 分区纹路总长度；

- 单位面积纹路总长度；

- P90纹路宽度；

- 全部稳定性线性皱纹标记；

## 7.5 稳定性线性皱纹报告示例

### 稳定性线性皱纹：64分，较明显

额部和右眼尾为重点区域。

额部检测到多条较长的水平线性纹路，纹路连续性较好，较宽纹路和较明显纹路较多；右眼尾放射状纹路的总长度和面积高于左侧。眉间及口周线性纹路相对较轻。

多数主要纹路在正面及侧面照片中可重复识别，部分较明显纹路在3D模型中存在对应的凹纹。综合表现提示面部存在较明显的稳定性线性皱纹外观，以额部和右眼尾为主。

| 眉间 | 43分 | 少量垂直线性纹路 |
| 左眼尾 | 58分 | 中度放射状纹路 |
| 右眼尾 | 67分 | 纹路长度和对比度高于左侧 |

| --- | --- | --- |
| 分区纹路总长度 | 额部偏高 | 额部线性皱纹总体延伸范围较大 |
| 较宽纹路 | 偏高 | 较宽一组稳定性线性皱纹较明显 |

# 八、医学说明、检测局限性与最终医学逻辑

## 8.1 医学说明与检测局限性

稳定性线性皱纹检测结果反映标准化照片及3D模型中的：

- 纹路数量；

- 长度、宽度和面积；

- 视觉对比度；

- 方向和线性形态；

- 多图稳定性；

- 相对三维凹陷；

- 分区分布及左右差异。

本报告不能直接判断：

- 胶原含量或胶原断裂程度；

- 真皮弹力纤维状态；

- 皮肤生物力学性能；

- 皱纹形成的具体病因；

- 动态表情对皱纹形成的长期贡献。

检测结果可能受到以下因素影响：

- 面部表情和肌肉紧张程度；

- 拍摄光照、曝光和阴影；

- 拍摄角度和距离；

- 图像分辨率及清晰度；

- 毛发、妆容和护肤品残留；

- 3D模型重建误差及物理尺度标定情况。

治疗前后或不同时间检测时，应尽量保持相同的拍摄设备、光照、距离、角度、面部放松状态及面部清洁状态。

## 8.2 最终医学逻辑

稳定性线性皱纹报告是一个独立的面部纹路图像表型报告。

其核心评价内容为：

**放松状态下稳定存在的线状皱纹有多少、延伸多长、宽度和视觉明显程度如何、是否符合典型方向、是否能在多张照片中重复识别，以及主要分布在哪里。**

3D模型用于为较明显的线性皱纹提供相对凹陷支持，但不替代二维照片对细线纹路的识别，也不用于推断胶原或真皮组织学状态。
