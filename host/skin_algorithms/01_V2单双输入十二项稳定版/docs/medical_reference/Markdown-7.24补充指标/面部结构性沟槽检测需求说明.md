# **面部结构性沟槽检测需求说明**

# 一、系统目标

系统通过用户的标准化正面、左右侧面照片及由照片重建的3D人脸模型，识别位于典型解剖区域、具有较宽、较长、较深及明显曲面变化的结构性沟槽，形成独立的面部结构性沟槽检测报告。

本报告主要评价：

**法令纹、木偶纹、颊中沟、泪沟及口角囊袋相关凹陷区域的解剖路径、长度、宽度、相对深度、体积、横截面、曲率、邻近隆起及左右差异。**

最终报告应回答以下问题：

- 各类结构性沟槽是否明显；

- 主要问题是法令纹、木偶纹、颊中沟、泪沟还是口角相关凹陷；

- 沟槽的长度、宽度、深度及体积负担是否较高；

- 沟槽是否具有稳定的三维凹谷和曲率变化；

- 沟槽旁是否存在明显邻近隆起或高低差；

- 左右两侧结构性沟槽是否存在差异；

- 结果在不同角度照片及3D模型中是否具有一致性。

本报告不直接评价：

- 额部、眉间、眼尾及口周稳定性线性皱纹；

- 眼下、颧部及面颊的干燥性细纹；

- 脂肪室下垂、韧带松弛或骨吸收的具体程度；

- 沟槽形成的具体解剖病因；

- 组织学或影像学诊断意义上的软组织改变。

# 二、医学定义

## 2.1 结构性沟槽

结构性沟槽是指位于典型面部解剖区域，表现为较宽、较深、较长，并具有三维凹陷、曲率或局部体积变化的沟槽样外观。

结构性沟槽通常包括：

- 法令纹；

- 木偶纹；

- 颊中沟，也称印第安纹；

- 泪沟；

- 口角囊袋相关凹陷区域。

口角囊袋本身常表现为局部隆起，因此评价相关区域时，应同时观察邻近凹陷、局部隆起及曲面高低差。

## 2.2 与其他纹路表型的区别

| **纹路类型** | **主要区别** |
| --- | --- |
| 结构性沟槽 | 符合典型解剖路径，通常较宽、较长，并具有明确三维凹谷、曲率或体积变化。 |
| 稳定性线性皱纹 | 以中等尺度、方向较明确、相对连续的线状纹路为主。 |
| 干燥性细纹 | 以短、细、浅、密集和多方向交织的细碎纹理为主。 |

三类纹路报告相互独立，不要求对每条候选纹路进行互斥分类。本报告只评价结构性沟槽符合程度。

## 2.3 医学解释边界

结构性沟槽评分反映照片和3D模型中的沟槽外观，不代表系统已确定其由脂肪下垂、韧带松弛、骨吸收或某一特定解剖变化导致。

# 三、主要检测区域

建议分别检测左右两侧以下结构性沟槽区域：

- 左法令纹；

- 右法令纹；

- 左木偶纹；

- 右木偶纹；

- 左颊中沟；

- 右颊中沟；

- 左泪沟；

- 右泪沟；

- 左口角囊袋相关凹陷区域；

- 右口角囊袋相关凹陷区域。

## 3.1 不同沟槽的重点识别内容

| **检测区域** | **重点识别表现** |
| --- | --- |
| 法令纹 | 鼻翼外侧向口角方向延伸的沟槽路径、深度、宽度、体积及邻近面颊隆起。 |
| 木偶纹 | 口角向下颌方向延伸的沟槽路径及口角下方曲面高低差。 |
| 颊中沟 | 颧部至中面颊区域的斜向凹陷、相对深度、曲率及左右差异。 |
| 泪沟 | 眶下内侧至外侧的凹陷路径、深度、宽度及与眶下组织的高低差。 |
| 口角囊袋相关凹陷 | 口角附近局部隆起与邻近凹陷共同形成的曲面不平衡。 |

## 3.2 分区检测的医学意义

- 分别评价不同结构性沟槽类型的负担；

- 比较左右对应沟槽的深度、宽度和体积；

- 识别局部沟槽与邻近隆起共同形成的高低差；

- 评价治疗前后不同解剖区域的变化。

## 3.3 无效或需谨慎检测区域

- 明显表情牵拉或非放松状态区域；

- 严重高光、阴影、遮挡或曝光异常区域；

- 毛发、妆容或产品残留影响边界判断的区域；

- 3D重建缺失、破面或曲面明显失真的区域；

- 无法可靠匹配左右解剖位置的区域。

# 四、需要检测的指标及医学意义

| **指标项目** | **需要检测的具体指标** | **医学意义** |
| --- | --- | --- |
| 解剖位置与路径 | 沟槽名称及左右侧 | 明确每个沟槽属于法令纹、木偶纹、颊中沟、泪沟或口角相关凹陷，并记录左右侧。 |
| 解剖位置与路径 | 沟槽起点与终点位置 | 记录沟槽在面部坐标中的起止位置，用于路径、长度及随访比较。 |
| 解剖位置与路径 | 典型解剖路径匹配程度 | 反映沟槽位置和走向是否符合相应结构性沟槽的常见解剖路径。 |
| 解剖位置与路径 | 多图位置一致性 | 反映沟槽在正面和侧面照片映射至同一面部位置后是否一致。 |
| 二维沟槽范围 | 沟槽总长度 | 反映沟槽沿典型路径延伸的总体范围。 |
| 二维沟槽范围 | 平均宽度 | 反映沟槽在主要路径上的平均影响宽度。 |
| 二维沟槽范围 | 最大宽度 | 反映沟槽最宽位置的局部范围，仅作为辅助指标。 |
| 二维沟槽范围 | P50沟槽宽度 | 反映典型沟槽横向宽度水平。 |
| 二维沟槽范围 | P90沟槽宽度 | 反映较宽一组沟槽区段的宽度水平。 |
| 二维沟槽范围 | 沟槽二维面积 | 反映沟槽长度和宽度共同形成的二维覆盖范围。 |
| 视觉对比度 | 沟槽平均对比度 | 反映沟槽与邻近皮肤之间的平均明暗差。 |
| 视觉对比度 | P90沟槽对比度 | 反映较明显沟槽区段的视觉突出程度。 |
| 视觉对比度 | 二维暗线与三维凹陷一致性 | 反映照片中的暗线是否具有对应的三维几何凹陷支持。 |
| 相对深度 | 平均相对深度 | 反映沟槽整体相对于周围面部曲面的平均凹陷程度。 |
| 相对深度 | 最大相对深度 | 反映沟槽最明显位置的相对凹陷程度。 |
| 相对深度 | P50相对深度 | 反映典型沟槽区段的相对深度水平。 |
| 相对深度 | P90相对深度 | 反映较深一组沟槽区段的相对深度水平。 |
| 沟槽体积 | 沟槽总体积 | 综合反映沟槽深度、宽度和长度形成的总体三维负担。 |
| 沟槽体积 | 单位长度沟槽体积 | 反映单位沟槽长度所对应的体积负担，减少沟槽长度差异的影响。 |
| 沟槽体积 | 局部最大体积负担 | 反映沟槽最明显区段的局部体积变化。 |
| 横截面形态 | 沟槽横截面积 | 反映垂直于沟槽路径的凹陷截面范围。 |
| 横截面形态 | 明确凹谷区段比例 | 反映沟槽路径中具有稳定凹谷横截面的区段占比。 |
| 横截面形态 | 谷底连续性 | 反映沟槽底部沿路径是否连续。 |
| 横截面形态 | 两侧坡度 | 反映沟槽两侧由周围皮肤下降至谷底的过渡陡峭程度。 |
| 横截面形态 | 两侧坡度对称性 | 反映沟槽左右两侧曲面过渡是否对称。 |
| 曲率变化 | 沟槽区域曲率 | 反映沟槽区域面部曲面的凹陷形态。 |
| 曲率变化 | 沟槽两侧曲率变化 | 反映沟槽两侧由隆起或平面向凹陷过渡的曲面变化。 |
| 曲率变化 | 曲面过渡程度 | 反映沟槽是否形成稳定的大尺度低频曲面凹陷。 |
| 邻近隆起 | 沟槽旁局部隆起高度 | 反映沟槽邻近软组织区域高于周围曲面的程度。 |
| 邻近隆起 | 沟槽旁局部隆起面积 | 反映邻近隆起影响皮肤表面的范围。 |
| 邻近隆起 | 沟槽旁局部隆起体积 | 反映邻近隆起的三维体积负担。 |
| 邻近隆起 | 沟槽与邻近隆起高低差 | 反映凹陷与邻近隆起共同造成的局部曲面反差。 |
| 路径连续性 | 沟槽连续长度比例 | 反映沟槽路径中连续可识别区段占总体路径的比例。 |
| 路径连续性 | 中断区段数量 | 反映沟槽路径是否存在多个明显中断。 |
| 路径连续性 | 多图形态一致性 | 反映沟槽在不同角度照片中的长度、宽度和走向是否稳定。 |
| 分区分布 | 各类沟槽评分 | 分别反映法令纹、木偶纹、颊中沟、泪沟及口角相关凹陷的负担。 |
| 分区分布 | 主要结构性沟槽类型 | 用于确定对全面部结构性沟槽结果贡献最大的沟槽类型。 |
| 分区分布 | 主要受累侧别 | 用于描述结构性沟槽主要为双侧、左侧偏重或右侧偏重。 |
| 左右不对称 | 左右沟槽长度差异 | 反映左右对应沟槽的延伸范围是否一致。 |
| 左右不对称 | 左右沟槽P90宽度差异 | 反映左右对应沟槽较宽区段的宽度水平是否存在差异。 |
| 左右不对称 | 左右平均及最大相对深度差异 | 反映左右对应沟槽的三维凹陷程度是否存在偏重。 |
| 左右不对称 | 左右沟槽体积差异 | 反映左右对应沟槽的总体三维负担是否一致。 |
| 左右不对称 | 左右邻近隆起及高低差差异 | 反映左右沟槽与邻近隆起共同形成的曲面反差是否存在差异。 |

# 五、结构性沟槽评分组成

结构性沟槽综合评分建议由以下指标组共同参与：

| **评分组成** | **建议初始权重** | **评分意义** |
| --- | --- | --- |
| 解剖路径匹配 | 15% | 评价沟槽是否位于典型解剖位置并符合相应路径和走向。 |
| 沟槽深度 | 25% | 评价平均、最大及P90相对深度。 |
| 沟槽范围 | 15% | 评价沟槽长度、宽度和横截面积。 |
| 沟槽体积 | 20% | 评价沟槽总体积及单位长度体积。 |
| 曲率和凹谷形态 | 15% | 评价沟槽是否具有稳定的三维凹谷、曲率变化和横截面表现。 |
| 邻近隆起 | 10% | 评价沟槽旁局部隆起及沟槽与隆起之间的高低差。 |

以上权重为第一版医学指导建议，后续可根据医学专家标注、3D重建稳定性、治疗前后变化及模型训练数据进行调整。

# 六、分区评分与结果等级

## 6.1 分区评分

建议分别输出以下结构性沟槽评分：

- 左法令纹评分；

- 右法令纹评分；

- 左木偶纹评分；

- 右木偶纹评分；

- 左颊中沟评分；

- 右颊中沟评分；

- 左泪沟评分；

- 右泪沟评分；

- 左右口角囊袋相关凹陷评分；

- 全面部结构性沟槽评分。

每个分区评分应综合反映：

- 典型解剖路径匹配；

- 沟槽长度和宽度；

- 平均、最大及P90相对深度；

- 沟槽总体积及单位长度体积；

- 横截面凹谷和谷底连续性；

- 曲率及曲面过渡；

- 邻近隆起和局部高低差；

- 多图及3D表现一致性。

分区结果用于区分不同沟槽类型和左右侧负担，不应只输出一个全面部总分。

## 6.2 结果等级

第一版可暂时采用以下图像学等级：

| **综合评分** | **等级** |
| --- | --- |
| 0～20分 | 未见明显 |
| 21～40分 | 轻度 |
| 41～60分 | 中度 |
| 61～80分 | 较明显 |
| 81～100分 | 显著 |

以上等级属于基于照片及3D模型的结构性沟槽图像学分级，不代表组织学损伤程度或具体疾病严重程度。

具体分界值后续应根据以下数据进行重新标定：

- 医学专家视觉评分；

- 参考人群分布；

- 不同年龄及肤质人群数据；

- 标准化重复拍摄结果；

- 系统实际检测表现。

# 七、最终报告内容与示例

## 7.1 一级结果

- 结构性沟槽综合评分；

- 结构性沟槽等级；

- 主要结构性沟槽类型；

- 主要受累区域及侧别；

- 左右不对称情况。

## 7.2 二级结果

- 沟槽路径和范围；

- 沟槽深度表现；

- 沟槽体积负担；

- 横截面及凹谷形态；

- 曲率和曲面过渡；

- 邻近隆起及局部高低差；

- 多图与3D一致性；

- 各结构性沟槽分区评分。

## 7.3 核心指标

- 沟槽长度；

- P90沟槽宽度；

- 平均及最大相对深度；

- 沟槽总体积；

- 单位长度体积；

- 凹谷连续性；

- 邻近隆起及局部高低差；

- 左右差异。

## 7.4 可视化结果

- 各结构性沟槽路径标记；

- 沟槽深度及体积分布图；

- 横截面凹谷示意；

- 曲率变化区域显示；

- 邻近隆起及局部高低差显示；

- 左右对应沟槽比较。

可视化结果用于解释沟槽的二维和三维外观，不应将颜色或几何标记解释为脂肪、韧带或骨性结构的直接诊断。

## 7.5 结构性沟槽报告示例

### 面部沟纹明显度：71分，较明显

双侧法令纹是主要结构性问题，右侧重于左侧，同时伴右侧颊中沟较明显。

右侧法令纹的整体凹陷和延伸范围均高于左侧，较宽沟槽也更多；双侧泪沟为中度，木偶纹相对较轻。口角囊袋区域可见局部隆起与邻近凹陷形成的曲面高低差。

综合表现提示较明显的结构性沟槽外观，以右侧法令纹和右侧颊中沟为主。

### 核心指标示例

| **核心指标** | **检测结果** | **结果解释** |
| --- | --- | --- |
| 平均相对深度 | 右法令纹偏高 | 右侧法令纹整体凹陷程度较明显 |

# 八、医学说明、检测局限性与最终医学逻辑

## 8.1 医学说明与检测局限性

结构性沟槽检测结果反映标准化照片及3D模型中的：

- 解剖位置和路径；

- 沟槽长度、宽度和二维范围；

- 相对深度和体积；

- 横截面凹谷和曲率变化；

- 邻近隆起及局部高低差；

- 多图与3D一致性；

- 左右差异。

本报告不能直接判断：

- 脂肪室是否下垂及下垂程度；

- 韧带是否松弛；

- 骨吸收或骨性支撑变化；

- 具体软组织层次的解剖改变；

- 结构性沟槽形成的单一病因。

检测结果可能受到以下因素影响：

- 面部表情和头位；

- 拍摄角度、距离、光照及阴影；

- 照片与3D模型的配准误差；

- 3D重建精度、破面及曲面平滑处理；

- 真实物理尺度是否标定；

- 妆容、毛发和局部遮挡；

- 体重、软组织水肿及短期状态变化。

没有真实物理尺度标定时，深度和体积应作为相对或标准化指标解释，不应直接以真实毫米或立方毫米作医学结论。

治疗前后或不同时间检测时，应尽量保持相同的拍摄设备、光照、距离、角度、面部放松状态及3D重建流程。

## 8.2 最终医学逻辑

结构性沟槽报告是一个独立的大尺度面部曲面纹路图像表型报告。

其核心评价内容为：

沟槽是否位于典型解剖路径、延伸范围有多大、三维凹陷和体积负担有多明显、是否伴邻近隆起，以及左右两侧是否存在差异。

结构性沟槽的视觉明显程度通常由沟槽深度、宽度、体积、曲率和邻近隆起共同决定，不能仅根据二维暗线或单一深度指标判断。
