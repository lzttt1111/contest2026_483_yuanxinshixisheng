# **面部色素检测医学需求说明**

# 一、系统目标

通过标准化普通面部照片、UV图像、Brown综合色素图和Red红色图，对面部色素相关图像信号进行拆分和重组，评价色斑的可见程度、面积、颜色明显程度、形态、分布及多图像重叠关系，形成独立的面部色素检测报告。

本报告主要输出以下结果：

- 看得见的色斑；

- UV下更明显的色斑；

- 整体棕色色素；

- 红褐混合印记；

- 重点色斑区域。

本报告主要评价：

**面部色素在普通照片、UV图像及综合色素图中的可见程度和分布特点，以及同一区域是否同时伴有棕色和红色表现。**

最终报告应回答以下问题：

- 普通照片中能够看到多少色斑；

- 可见色斑覆盖范围有多大、颜色是否明显；

- 是否存在普通照片中不突出、但在UV图像中更明显的色素区域；

- 面部棕色色素的整体范围和信号强度如何；

- 是否存在同时伴棕色和红色表现的印记；

- 哪些区域在普通照片、UV图像和Brown综合色素图中均较明显；

- 色素以点状、片状还是混合形态为主；

- 色素主要集中在哪些面部区域；

- 左右两侧色素负担是否存在差异。

本报告不直接评价：

- 具体色素性疾病；

- 色素位于表皮还是真皮；

- 真实黑色素绝对含量；

- 色素形成的具体原因；

- UV图中的色素区域未来是否一定显现；

- 色斑是否顽固或治疗难度；

- 具体治疗方案。

# 二、医学定义

## 2.1 看得见的色斑

“看得见的色斑”是指：

**在标准化普通面部照片中，与周围皮肤相比表现为更深、更棕或综合色差更明显，并达到系统识别标准的局部色素目标。**

该结果主要反映当前普通照片中已经能够观察到的棕色色斑，包括其数量、面积、颜色明显程度、点状或片状形态及主要分布区域。

检测时应尽量排除明显红色目标、毛发和眉毛、彩妆、阴影、鼻翼及唇缘等解剖边缘、高光边界、痂皮及其他表面附着物。

## 2.2 UV下更明显的色斑

“UV下更明显的色斑”是指：

**在普通照片中不明显或相对不突出，但在标准化UV图像中表现更明显的色素信号区域。**

该结果仅表示色素信号在UV图像中更突出，不表示色素隐藏在真皮深层、未来一定转为肉眼可见色斑、一定由紫外线造成或一定会继续加重。

## 2.3 整体棕色色素

“整体棕色色素”是指：

**Brown综合色素图中显示的黑色素相关棕色成分，包括普通照片中已经可见以及当前普通照片中相对不明显的棕色色素区域。**

该结果主要反映面部棕色色素的整体范围、信号强度、点状和片状组成、主要分布区域及左右差异。

整体棕色色素不能直接解释为真皮浅层色斑、深层色斑、真皮黑色素、顽固性色斑或更难治疗的色斑。

## 2.4 红褐混合印记

“红褐混合印记”是指：

**同一个综合色差区域同时具有普通照片中的可见综合色差、Brown综合色素图中的棕色表现和Red红色图中的红色表现。**

用户端可以解释为“这些印记不只是棕色，还伴有一定红色表现”。该结果不能单独诊断痘印、炎症后色素沉着、活动性炎症、毛细血管扩张或痤疮。

## 2.5 重点色斑区域

“重点色斑区域”是指：

**同一区域在普通照片、UV图像和Brown综合色素图中均表现较明显，并由多种图像结果共同支持的色斑区域。**

“重点”仅表示多种图像共同支持，用于报告高亮和随访比较，不表示色斑更深、更顽固、治疗难度更高或一定属于某种疾病。

## 2.6 图像结果之间的关系

五项结果可以相互重叠，但用途不同：

- 看得见的色斑反映当前普通照片中的可见色斑负担；

- UV下更明显的色斑反映普通照片中不突出、但UV图中更明显的色素信号；

- 整体棕色色素反映Brown综合色素图中的总体棕色负担；

- 红褐混合印记用于描述同一区域内棕色和红色信号并存；

- 重点色斑区域用于标记多种图像共同支持的主要观察区域。

红褐混合印记和重点色斑区域属于辅助结果，不应与前三项面积简单相加。

# 三、主要检测区域

建议对以下面部区域分别检测：

- 额部；

- 左眼周；

- 右眼周；

- 左颧部；

- 右颧部；

- 鼻部；

- 左面颊；

- 右面颊；

- 口周；

- 下颌及下巴。

其中重点报告区域通常包括：

- 双侧颧部；

- 鼻部；

- 面颊上部；

- 口周及下颌。

## 3.1 分区检测的医学意义

分区检测可以用于：

- 判断色素问题主要集中在哪些区域；

- 比较颧部、鼻部、面颊及口周的色素负担差异；

- 比较点状与片状色素在不同区域的组成；

- 比较普通照片、UV图像和Brown综合色素图在同一区域的表现；

- 识别左右不对称或明显单侧集中；

- 评价治疗或护理前后重点区域的变化。

不同分区面积不同，因此跨区域比较时，应优先使用单位面积目标密度、色素面积占比和强度水平，而不是只比较目标数量或绝对面积。

# 八、医学说明、检测局限性与最终医学逻辑

## 8.1 医学说明与检测局限性

面部色素检测结果反映标准化图像中的：

- 色素可见程度；

- 目标数量和密度；

- 色素面积和覆盖范围；

- 颜色或图像信号强度；

- 点状、片状及融合形态；

- 普通照片、UV图像、Brown综合色素图和Red红色图中的表现；

- 分区分布及左右差异。

本报告不能直接判断：

- 具体色素性疾病；

- 色素位于表皮还是真皮；

- 真实黑色素含量；

- 色素形成原因；

- UV图中的区域未来是否一定显现；

- 色斑是否顽固或治疗难度；

- 红褐混合印记是否属于痘印、炎症后色素沉着或活动性炎症；

- 具体治疗方案。

检测结果可能受到以下因素影响：

- 光照和曝光；

- 拍摄角度和距离；

- 图像清晰度；

- 肤色及局部阴影；

- 毛发和眉毛；

- 底妆、遮瑕及其他彩妆；

- 护肤品、防晒及表面附着物；

- 鼻翼、唇缘等解剖边缘；

- 不同设备的UV及综合色素处理参数。

治疗前后或不同时间检测时，应尽量保持相同的拍摄设备、光照、距离、角度、曝光、面部清洁状态及产品使用情况。

## 8.2 最终医学逻辑

面部色素报告是一个基于多种图像结果的综合色素图像表型报告。

其核心评价内容为：

**普通照片中能看到多少色斑，UV图中是否存在更明显的色素区域，Brown综合色素图中的整体棕色色素有多广，以及哪些综合色差区域同时伴有红色表现。**

看得见的色斑、UV下更明显的色斑和整体棕色色素分别评价不同图像层面的色素负担；红褐混合印记用于补充颜色组成，重点色斑区域用于定位多图共同支持的主要观察区域。
