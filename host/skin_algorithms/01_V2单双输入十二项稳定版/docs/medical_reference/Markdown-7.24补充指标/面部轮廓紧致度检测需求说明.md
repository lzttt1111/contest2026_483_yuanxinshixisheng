# **面部轮廓紧致度检测医学需求说明**

# **一、系统目标**

系统输入用户标准化面部照片及由照片重建的3D人脸模型，对中面部和下脸的表面凹凸、结构性沟槽、局部隆起及下颌缘轮廓进行测量，形成面部轮廓紧致度检测报告。

本系统主要评价：

- 中面部曲面是否平滑、连续；

- 面部是否出现明显的凸凹转折；

- 法令纹、颊中沟、木偶纹等结构性沟槽是否明显；

- 口角外下方和下颌缘是否出现局部凹陷或隆起；

- 下颌缘是否保持连续、平滑；

- 左右两侧是否存在明显差异；

- 与历史检测相比，面部轮廓是否发生变化。

系统最终输出：

- 面部轮廓紧致度下降总分；

- 中面部曲面支撑下降评分；

- 结构性沟槽负担评分；

- 下脸轮廓松垂评分；

- 左右不对称结果；

- 主要问题区域；

- 检测结果的医学解释；

- 存在历史检测时的纵向变化结果。

本系统评价的是照片和3D模型中的面部表面形态，不直接检测皮肤弹性、脂肪室位置、韧带松弛、肌肉状态或骨性支撑。

# **二、医学定义**

## **2.1 面部轮廓紧致度**

面部轮廓紧致度，是指中面部至下脸的表面曲线保持相对平滑、连续，结构性沟槽和局部凹凸转折不明显，下颊无明显低位隆起，下颌缘轮廓相对清晰、连续的面部外观状态。

## **2.2 面部轮廓紧致度下降**

面部轮廓紧致度下降，是指面部出现以下一种或多种表面表现：

- 面颊曲面连续性下降；

- 面颊凸凹转折增多；

- 颊中部或鼻旁出现明显凹陷；

- 法令纹、颊中沟、木偶纹等结构性沟槽加重；

- 口角外下方出现凹陷；

- 下颊出现局部低位隆起；

- 出现Jowl样隆起；

- 颏前沟形成或加深；

- 下颌缘连续性下降；

- 下颌缘曲率波动增加。

这些表现可能与软组织松垂有关，也可能受到先天骨相、脸型、脂肪量、体重、表情活动、局部容量差异及既往医美治疗等因素影响。

因此，本报告评价的是“面部轮廓紧致度下降样表型”，不直接判断具体的解剖原因。

## **2.3 三个组成表型**

### **中面部曲面支撑下降**

指颧部至口角水平区域的曲面由相对平滑连续，转变为明显凹陷、隆起和多次凸凹转折的表面表现。

### **结构性沟槽负担**

指法令纹、颊中沟、木偶纹、口角外下方凹陷、颏前沟及泪沟等大尺度沟槽的长度、宽度、深度和体积负担。

### **下脸轮廓松垂**

指口角水平以下出现下颊局部隆起、Jowl样隆起、颏前沟、下颌缘中断及轮廓凹凸波动等表现。

# **三、主要检测区域**

## **3.1 中面部区域**

中面部主要包括：

- 下睑以下区域；

- 颧部；

- 前内侧面颊；

- 外侧面颊；

- 颊中部；

- 鼻旁区域；

- 颊中沟区域；

- 口角水平以上的面颊区域。

## **3.2 下脸区域**

下脸主要包括：

- 口角水平以下区域；

- 口角外下方区域；

- 木偶纹区域；

- 下颊区域；

- Jowl样隆起区域；

- 颏前沟区域；

- 下颌缘；

- 下巴两侧。

## **3.3 中面部与下脸的分界**

建议以双侧口角连线作为中面部与下脸的主要功能性分界。

考虑到法令纹末端、木偶纹起点、口角外下方凹陷及下颊隆起可能跨越口角水平，建议在口角连线上下设置过渡区域。过渡区域中的目标可以同时参与中面部曲面支撑评价、结构性沟槽评价和下脸轮廓评价。

口角连线仅用于本项目的功能性分区，不等同于传统面部三等分中的中面部与下面部边界。

## **3.4 左右分区**

以下区域应分别测量左侧和右侧：

- 颊中部；

- 鼻旁；

- 法令纹；

- 颊中沟；

- 泪沟；

- 木偶纹；

- 口角外下方凹陷；

- 颏前沟；

- Jowl样隆起；

- 下颌缘。

# **四、需要检测的指标及医学意义**

## **4.1 中面部曲面指标**

| **指标项目** | **需要检测的具体指标** | **医学意义** |
| --- | --- | --- |
| 面颊曲面连续性 | 从颧部向下经过面颊至口角水平的曲面连续性；突然凹陷、突然隆起、曲面中断的数量和范围。 | 曲面连续性下降说明面颊表面被凹陷、沟槽或低位隆起分割，紧致、平滑的轮廓外观下降。面颊整体平坦不能单独代表紧致度下降。 |
| 面颊凸凹转折数量 | 从颧部到下颊的曲面中，凸面转凹面及凹面转凸面的次数。 | 转折越多，越容易形成“颧部凸起—颊中部凹陷—下颊再次隆起”等多层次表面变化，松垂样外观越明显。 |
| 凸凹转折幅度 | 颧部与颊中沟、颊中部凹陷与下颊隆起、下颊隆起与颏前沟之间的高低差。 | 高低差越明显，面部曲面分割和阴影越明显，视觉紧致度越低。 |
| 颊中部凹陷 | 凹陷面积；平均相对深度；最大相对深度；P90相对深度；凹陷体积；与周围隆起的高低差。 | 破坏颧部至下颊的连续曲面，可加重颊中沟、疲惫感及中面部支撑不足样外观；不能单独判断凹陷的解剖原因。 |
| 鼻旁凹陷 | 凹陷面积；平均相对深度；最大相对深度；凹陷体积；与法令纹连续程度；与周围面颊的高低差。 | 可增加法令纹起始区域的视觉深度，并形成中面部支撑不足样外观。 |
| 下颊低位隆起 | 隆起面积；平均与最大隆起高度；隆起体积；隆起中心位置；与颊中部凹陷的高低差。 | 下颊隆起尤其伴颊中部凹陷时，可形成组织视觉重心低位集中样外观。 |

## **4.2 结构性沟槽指标**

需要分别检测法令纹、颊中沟（印第安纹）、木偶纹、口角外下方凹陷、颏前沟及泪沟。每条结构性沟槽需要测量以下指标。

| **指标项目** | **需要检测的具体指标** | **医学意义** |
| --- | --- | --- |
| 沟槽长度 | 沟槽沿面部表面的延伸长度。 | 反映沟槽影响范围。 |
| 沟槽宽度 | 平均宽度、最大宽度、P50宽度、P90宽度。 | 反映沟槽展开程度；宽度较大并伴明显深度和体积，更支持结构性沟槽表型。 |
| 沟槽深度 | 平均相对深度、最大相对深度、P50深度、P90深度。 | 反映沟槽相对于周围参考曲面的凹陷程度。 |
| 沟槽面积 | 沟槽在面部表面的覆盖面积。 | 反映沟槽的表面影响范围。 |
| 沟槽体积 | 沟槽总体积、单位长度沟槽体积、标准化沟槽体积。 | 综合反映长度、宽度和深度，是结构性沟槽严重度的重要指标。 |
| 横截面积与凹谷形态 | 垂直于沟槽方向的横截面积；是否呈稳定的“高—低—高”凹谷结构。 | 用于区分真实曲面凹陷与单纯颜色暗线或阴影。 |
| 凹谷连续性 | 沟槽沿路径连续存在的程度。 | 连续且稳定的凹谷较局部、间断性阴影更支持结构性沟槽。 |
| 邻近隆起及高低差 | 沟槽两侧隆起高度或体积；沟槽与邻近隆起之间的高度差。 | 结构性沟槽的视觉严重度常由“凹陷＋邻近隆起”共同形成。 |

### **不同结构性沟槽的医学含义**

| **沟槽类型** | **医学含义与解释边界** |
| --- | --- |
| 法令纹 | 反映鼻旁至口角区域的结构性沟槽负担。可受鼻旁凹陷、面颊软组织分布、局部解剖结构、表情活动及先天组织厚度差影响，不能直接认定为脂肪下垂。 |
| 颊中沟（印第安纹） | 反映颧部与中面颊之间的结构性分界。加深时会破坏面颊曲面连续性，并增加中面部松垂样或疲惫样外观。 |
| 泪沟 | 反映下睑与上面颊之间的凹陷。受先天眶周结构影响明显，因此在紧致度总分中的权重应相对较低。 |
| 木偶纹 | 指从口角向下延伸的沟槽。明显时常伴口角外下方凹陷及下颊隆起，对下脸轮廓紧致度影响较明显。 |
| 口角外下方凹陷 | 位于口角外侧或外下方，可表现为局部凹陷、沟槽或与木偶纹连续的结构；比单纯口角垂直位置更适合评价下垂样外观。 |
| 颏前沟 | 又称Prejowl sulcus、颏旁沟或下颌缘前凹陷，位于下巴外侧、Jowl样隆起前方；加深时会破坏下颌线连续性。 |

## **4.3 下脸轮廓指标**

| **指标项目** | **需要检测的具体指标** | **医学意义** |
| --- | --- | --- |
| Jowl样隆起 | 隆起面积；平均与最大隆起高度；隆起体积；向下超过参考下颌缘的程度；隆起中心位置。 | 反映口角外下方或下脸外侧的下颊垂坠、囊袋或局部组织堆积样外观，但不能直接解释为脂肪垫下移。 |
| 下颌缘连续性 | 下颌缘连续长度；轮廓中断数量；凹陷数量；隆起数量；轮廓线平滑程度。 | 下颌缘越连续平滑，轮廓紧致感通常越强；颏前沟和Jowl样隆起越明显，连续性越差。 |
| 下颌缘曲率波动 | 曲率方向变化次数；曲率变化幅度；局部凹陷与隆起之间的高低差；左右差异。 | 波动增加说明下颌缘由连续轮廓转变为多次凹凸转折。 |
| 颏前沟 | 长度；平均宽度；平均与最大深度；凹陷面积和体积；与下巴凸度及Jowl样隆起的高低差。 | 加深时形成“下巴凸起—颏前沟凹陷—Jowl样隆起”的明显转折，降低下颌线连续性。 |
| 口角外下方凹陷 | 凹陷位置；长度；宽度；平均与最大深度；面积；体积；与木偶纹连续程度；与下颊隆起的高低差。 | 比单纯口角垂直位置更适合反映下脸松垂样表面形态。 |

## **4.4 左右不对称指标**

分别比较左右两侧的颊中部凹陷、鼻旁凹陷、结构性沟槽深度和体积、Jowl样隆起、颏前沟、下颌缘连续性及下颌缘曲率波动。左右不对称作为单独结果展示，不直接等同于全面部严重程度。

## **4.5 单次检测辅助指标**

以下指标受先天脸型、骨相、脂肪量或体重影响较大，单次检测中只作为辅助结果，不作为核心评分依据：

- 面颊最高凸点位置；

- 面颊体积重心位置；

- 上下颊体积比；

- 下脸宽度；

- 颧宽与下脸宽度比；

- 面颊平均曲率；

- 口角垂直位置。

## **4.6 纵向随访指标**

当存在同一用户历史照片或历史3D模型时，可测量：

- 面颊最高凸点位置变化；

- 面颊体积重心位置变化；

- 上下颊体积比变化；

- 下脸宽度变化；

- 颊中部凹陷变化；

- 鼻旁凹陷变化；

- 结构性沟槽深度和体积变化；

- Jowl样隆起面积和体积变化；

- 颏前沟变化；

- 下颌缘连续性变化；

- 下颌缘曲率波动变化。

这些指标在同一个人的随访中价值高于单次横断面评价。

# **五、面部轮廓紧致度下降评分组成**

## **5.1 中面部曲面支撑下降评分**

| **指标组** | **初始医学权重** |
| --- | --- |
| 面颊曲面连续性 | 30% |
| 凸凹转折数量及幅度 | 25% |
| 颊中部凹陷 | 20% |
| 鼻旁凹陷 | 15% |
| 下颊低位隆起 | 10% |

分数越高，表示中面部曲面支撑下降样表型越明显。

## **5.2 结构性沟槽负担评分**

不同沟槽建议初始权重：

| **沟槽类型** | **初始权重** |
| --- | --- |
| 法令纹 | 25% |
| 颊中沟 | 20% |
| 木偶纹 | 20% |
| 口角外下方凹陷 | 15% |
| 颏前沟 | 15% |
| 泪沟 | 5% |

每类沟槽内部根据以下指标共同评分：

| **指标组** | **建议内部权重** |
| --- | --- |
| 深度 | 25% |
| 体积 | 25% |
| 宽度及长度 | 20% |
| 横截面及凹谷形态 | 15% |
| 凹谷连续性 | 5% |
| 邻近隆起及高低差 | 10% |

## **5.3 下脸轮廓松垂评分**

| **指标组** | **初始医学权重** |
| --- | --- |
| Jowl样隆起 | 30% |
| 下颌缘连续性 | 25% |
| 下颌缘曲率波动 | 15% |
| 颏前沟 | 15% |
| 口角外下方凹陷 | 10% |
| 其他下颊局部隆起 | 5% |

## **5.4 面部轮廓紧致度下降总分**

| **一级项目** | **初始权重** |
| --- | --- |
| 中面部曲面支撑下降 | 30% |
| 结构性沟槽负担 | 30% |
| 下脸轮廓松垂 | 40% |

下脸轮廓松垂权重略高，是因为Jowl样隆起、颏前沟及下颌缘连续性下降，相对于面颊绝对凸度或脸宽，更能反映明显的轮廓松垂样外观。左右不对称不直接计入综合严重度总分，单独输出。

上述权重均为第一版医学建议，后续应通过专家标注和训练数据调整。

# **六、分区评分及结果等级**

## **6.1 分区评分**

| **评分项目** | **需要分别输出的分区** |
| --- | --- |
| 中面部曲面支撑 | 左侧中面部、右侧中面部、左侧颊中部、右侧颊中部、左侧鼻旁、右侧鼻旁。 |
| 结构性沟槽 | 左右法令纹、左右颊中沟、左右木偶纹、左右口角外下方凹陷、左右颏前沟、左右泪沟。 |
| 下脸轮廓 | 左右Jowl样隆起、左右下颌缘、左右下颊。 |

## **6.2 结果等级**

| **分数** | **结果等级** |
| --- | --- |
| 0～20 | 未见明显 |
| 21～40 | 轻度 |
| 41～60 | 中度 |
| 61～80 | 较明显 |
| 81～100 | 显著 |

等级阈值应在积累医生标注数据和参考人群数据后重新校准。

## **6.3 左右差异等级**

左右差异建议单独分为：基本对称、轻度不对称、中度不对称、明显不对称。左右不对称结果应说明哪一侧更明显、主要差异来自哪个指标以及差异集中在哪个区域。

# **七、最终报告内容与示例**

## **7.1 最终报告应包含的内容**

### **一级总览**

- 面部轮廓紧致度下降总分及等级；

- 中面部曲面支撑下降评分；

- 结构性沟槽负担评分；

- 下脸轮廓松垂评分；

- 左右不对称结果；

- 检测可信度。

### **分区结果**

- 左右中面部评分；

- 各结构性沟槽评分；

- 左右下脸评分；

- 主要问题区域。

### **核心指标**

每项报告显示3～5个主要贡献指标，例如：面颊曲面连续性、凸凹转折幅度、法令纹单位长度体积、Jowl样隆起体积、下颌缘连续性、颏前沟深度。

### **辅助指标**

面颊最高凸点位置、体积重心、上下颊体积比及下脸宽度。辅助指标应明确标注“受先天脸型和骨相影响，仅供参考”。

### **随访结果**

存在历史检测时，输出指标变化量、变化百分比、主要改善区域、主要加重区域及左右变化差异。

## **7.2 示例报告**

### **面部轮廓紧致度下降：64分，较明显**

本次检测显示面部存在较明显的轮廓紧致度下降样外观，主要表现为结构性沟槽负担增加、右侧下颊局部隆起及下颌缘连续性下降。

### **中面部曲面支撑下降：55分，中度**

双侧颊中部存在中度凹陷，颧部至下颊的曲面连续性一般。面颊表面可见“上部凸起—中部凹陷—下部再次隆起”的凸凹转折，其中右侧转折幅度高于左侧。右侧鼻旁凹陷相对明显，并与右侧法令纹起始区域连续。

### **面部沟纹明显度：67分，较明显**

双侧法令纹是主要结构性沟槽，右侧法令纹的整体凹陷和延伸范围均高于左侧，较宽沟槽也更多。右侧颊中沟和颏前沟相对明显，木偶纹及泪沟负担较轻。右侧口角外下方凹陷与下颊隆起之间形成较明显的高低差。

### **下脸轮廓松垂：71分，较明显**

右侧口角外下方及下颌缘上方存在较明显的Jowl样隆起，伴右侧颏前沟加深。双侧下颌缘连续性下降，右侧下颌缘的曲率波动和轮廓中断程度高于左侧。

### **左右差异**

整体呈右侧轮廓松垂样外观更明显，主要差异来自右侧法令纹体积较高、右侧颊中沟较深、右侧Jowl样隆起较明显、右侧颏前沟较深以及右侧下颌缘连续性较差。

### **综合评价**

1.  中面部曲面连续性下降；

2.  法令纹和右侧颊中沟等结构性沟槽较明显；

3.  右侧下颊出现Jowl样隆起；

4.  颏前沟加深并导致下颌缘连续性下降。

### **关键指标日常注释**

| **关键指标** | **本例表现** | **居家理解** |
| --- | --- | --- |
| 面颊表面连续性 | 中等下降 | 从颧部到下颊的轮廓不够平顺，凹凸变化更明显 |
| 法令纹和颊中沟 | 右侧更明显 | 右侧沟纹看起来更深、更宽，延伸范围更大 |
| 下颊局部鼓起 | 右侧较明显 | 右侧嘴角外下方和下颌线上方的局部鼓起更容易看见 |
| 下颌线连续性 | 右侧较低 | 右侧下颌线的凹凸和中断感更明显 |

> **关键指标日常注释：** 轮廓紧致感主要看面颊是否平顺、沟纹是否明显、下颊是否出现局部鼓起以及下颌线是否连贯。体重、水肿、表情、光线和拍摄角度都会影响结果，建议在相同条件下复测并观察长期趋势。

# **八、医学说明、检测局限与最终医学逻辑**

## **8.1 医学说明**

本报告评价的是面部照片和3D模型中呈现的曲面连续性、凸凹转折、结构性沟槽、局部隆起及下颌缘轮廓。报告中的“中面部曲面支撑下降”“结构性沟槽负担”和“下脸轮廓松垂”均属于图像和三维表面表型。

这些结果可以反映面部紧致度下降样外观，但不能直接确定其具体解剖原因。

## **8.2 检测局限**

系统不能直接检测：

- 胶原含量；

- 皮肤真实弹性；

- 筋膜状态；

- 韧带松弛；

- 肌肉位置和力量；

- 脂肪室边界及真实下移；

- 骨吸收；

- 骨性支撑；

- 组织学改变。

照片重建的3D模型还可能受到拍摄角度、面部表情、光照、遮挡、妆容、重建模型平滑、缺少真实物理尺度以及不同时间体重或水肿变化的影响。

如果3D模型没有物理尺度标定，应输出相对深度、标准化体积、归一化宽度及相对于面宽或ROI尺寸的比例，不应直接输出未经标定的毫米或立方毫米结果。

## **8.3 单次检测的解释原则**

单次检测主要评价用户当前是否呈现明显的面部轮廓紧致度下降样表型。

单次检测不应根据以下单一指标直接判断松垂：

- 面颊最高点较低；

- 面颊较平；

- 下脸较宽；

- 口角位置较低；

- 上下颊体积比异常。

这些指标受到先天脸型、骨相、脂肪量和体重影响较大，只能作为辅助信息。

## **8.4 随访检测的解释原则**

同一个用户不同时间的检测可以更有效地观察面颊体积重心变化、上下颊体积比变化、下脸宽度变化、Jowl样隆起变化、结构性沟槽变化及下颌缘连续性变化。

但随访仍需结合体重变化、水肿、拍摄姿势、表情、填充治疗、咬肌变化及口腔治疗等因素。

## **8.5 参考数据库的解释原则**

在没有用户历史数据时，可将当前结果与年龄、性别、BMI和脸型相近的参考人群比较，用于评价当前表型相对于相似人群的偏离程度。参考数据库不能直接证明某一用户的软组织实际下移了多少。

## **8.6 最终医学逻辑**

本报告不以“面颊最高点是否足够高”“脸是否足够窄”“口角是否足够上扬”作为面部紧致度的主要判断依据。

面部轮廓紧致度下降主要根据面颊曲面连续性下降、凸凹转折增加、结构性沟槽加深、口角外下方凹陷、Jowl样隆起、颏前沟加深以及下颌缘连续性下降进行综合判断。

- 单次检测评价当前松垂样外观；

- 纵向随访评价同一个人的变化趋势；

- 参考数据库评价相对于相似年龄、性别、BMI和脸型人群的偏离程度。

本报告能够描述面部轮廓紧致度下降样表型，但不能替代对皮肤弹性、脂肪室、韧带、肌肉和骨骼的直接检查。
