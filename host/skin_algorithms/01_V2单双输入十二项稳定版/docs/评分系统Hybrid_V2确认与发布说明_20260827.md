# DermaVision Hybrid V2 评分确认与发布说明

更新时间：2026-08-27

## 1. 当前发布结论

- 机器/云端长期评分仍以V0.1.1四项和Hybrid candidate边界为准；2026-08-28因上线时限新增一个只影响Word展示层的临时人群参考评分。
- Hybrid V2处于`candidate`阶段；确认报告、用户批准和生产allowlist完成前，生产loader拒绝加载。
- 新增七项为参考人群工程相对负担，不是临床轻中重，不生成十一项总分。
- 新七项长期promotion门保持不变；临时Word经用户明确授权，先按冻结1000张参考分布显示相对分数和等级，不回写机器JSON或Worker字段。
- Worker Task、Queue、四参数、六字段信封及公开`raw_result`不变。
- 当前正式测试目录回归：`571 passed + 696 subtests`；本轮评分代码编译通过。

## 3. 旧四项开发集候选

每个outer fold只在outer-train拟合映射，并在对应outer-validation生成OOF预测；五折OOF汇总后按跨两档数量、严重反转率、MAE、P95字典序选择方法。additive的λ只在各outer-train内部的4-fold inner CV选择。数值相同优先`identity → scalar_pava → fixed_group_pava → additive`。

## 4. 新七项开发候选

`population_ecdf_hybrid_v1`执行两层ECDF：指标百分位按冻结权重聚合为模块原始分，模块原始分再映射为0～100参考人群相对负担分。合法0与缺失`null`严格分离；运行时required指标缺失时整模块不可评估，禁止动态重分权。

## 5. 确认与发布门

旧四项每维要求：有效主体≥200、MAE≤6、P95≤15、Spearman≥0.90、严重可比pair≥1000、主体cluster bootstrap 2000次的严重反转率95%上界≤1%、跨两档数0，并且不劣于identity基线。

新模块要求：可评估率≥95%、0分率≤5%、100分率≤5%、端点合计≤10%、中位数35～65、IQR≥20、方向扰动100%通过、空证据写0数量为0。

## 6. 两阶段命令

确认评估完成后，先构建candidate：

```bash
python scripts/scoring/build_hybrid_candidate.py \
  --compatibility-profile COMPATIBILITY.json \
  --population-profile POPULATION.json \
  --confirmation-report CONFIRMATION.json \
  --development-manifest DEVELOPMENT.jsonl \
  --fold-manifest DEVELOPMENT_FOLDS.jsonl \
  --fold-metadata DEVELOPMENT_FOLDS.metadata.json \
  --legacy-root LEGACY_ROOT \
  --confirmation-manifest CONFIRMATION.jsonl \
  --confirmation-pairs CONFIRMATION_PAIRS.jsonl \
  --confirmation-metadata CONFIRMATION.metadata.json \
  --official-profile 00_runtime_assets/scoring_v011/全量历史ECDF评分配置.json \
  --formula-registry calibration/v2_explicit_formula_registry_v1.json \
  --code-sha GIT_SHA \
  --output hybrid_candidate.json
```

该命令成功只表示candidate构建完成，不允许发布。批准记录齐全后才可运行：

```bash
python scripts/scoring/promote_hybrid_profile.py \
  --candidate hybrid_candidate.json \
  --approvals approvals.jsonl \
  --output hybrid_promoted.json
```

批准记录绑定reviewer、日期、candidate profile SHA、确认集SHA、项目结论和文字结论。缺失、篡改或结论为blocked时命令非零退出。

## 7. 报告与回滚

- 旧四项：技术确认通过且用户批准后，才可显示兼容分；否则逐维回退V0.1.1。
- 新七项长期正式化仍要求每个技术通过模块完成30例医生审阅；临时Word上线不等于医学阈值批准。
- 用户版和医生版当前均展示临时参考分，但不得用于疾病诊断、治疗决策或疗效评价。
- candidate、blocked、SHA不在allowlist或文件被篡改时，生产loader失败关闭。
- 回滚只需移除Hybrid allowlist并继续加载随仓V0.1.1资产；检测算法、Worker合同和原始量化值均不变。
