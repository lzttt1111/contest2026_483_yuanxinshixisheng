# BiSeNet本机试运行

## 当前入口

http://127.0.0.1:8896/

该入口是本机试运行，不是远程云端发布。旧8892/8894未停止或覆盖。支持one/two两组、毛孔/可见色斑/表面油光、实际检测图/本次有效皮肤/修复前有效皮肤切换及放大。

启动：在本目录使用已安装依赖的Python运行 `serve_bisenet_trial.py`。服务仅监听127.0.0.1，不读取用户指定的任意路径，只展示本轮生成的白名单结果。

## 本轮已验证

- BiSeNet/ResNet18正式接入独立沙箱预处理类，模式 `bisenet_rgb_diagnostic_v1`；保持官方模型输入定义，不运行自制毛发暗纹规则。
- 特殊头饰按用户最新指示不阻止本机试用，不以此继续更换已选定方案；该类输入不作为已经验证准确的测量场景。
- 两组三视图六张实际执行，明确算法集合只有pores/spots/surface_gloss，总计18项成功；执行器服务只有dermavision，没有加载痤疮或皱纹服务。
- 实际执行器的六张分析图和有效皮肤Mask，与选型接线结果逐像素一致。
- 6个状态接口、54个图片响应完成检查，图片均能解码。
- 浏览器已检查两组切换、新预处理和实际色斑结果展示；非旧页面截图。
- 单张三项任务约6.39～9.55秒，另有冷启动；这是本机记录，不是云端性能承诺。

## 评分兼容上线状态

两组三视图已完成评分对照与自包含Celery验收。当前不重跑1000例：缺失的新预处理分区从包内旧评分回退文件补齐，因此网页和JSON可以显示整体/分区分数及严重程度；`reference_matches_new_preprocessing=false`，不能把它描述成新参考已经重新标定。正式远程Redis部署仍需按部署说明配置。
