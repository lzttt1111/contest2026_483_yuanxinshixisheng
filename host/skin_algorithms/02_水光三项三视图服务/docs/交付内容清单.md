## 自包含规则

运行时代码路径必须从当前包根派生。包内 V3 服务允许优先使用本包 `.venv`，其次使用启动进程的 Python；这属于“包外虚拟环境可用”的授权范围。不得从其他工程 import 评分、模型、参考或业务代码。

`PACKAGE_MANIFEST.json` 列出每个文件的 SHA256 和大小。执行：

```bash
uv run --frozen python scripts/verify_package.py
```

会核对核心目录、评分参考 SHA、示例结构、116 包锁定状态所需文件和绝对开发路径泄漏。
