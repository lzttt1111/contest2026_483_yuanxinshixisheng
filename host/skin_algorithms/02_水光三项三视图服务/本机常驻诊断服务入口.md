# 本机常驻诊断服务入口

当前提供两种入口，均只监听本机，不代表远程云端正式发布：

- 验收网页：http://127.0.0.1:8896/ ，查看两组三视图、预处理和评分诊断对照。
- 队列网关：http://127.0.0.1:8897/docs ，提交 `POST /api/diagnostic-jobs` 并按queue_id查询。

从本打包目录启动本地演示（两个终端）：

```bash
uv run --no-sync python scripts/run_local_diagnostic_service.py worker
uv run --no-sync python scripts/run_local_diagnostic_service.py api
```

本地演示明确使用文件系统Celery传输，输入根为包内 `examples`，运行产物在 `runtime/local_diagnostic_service`。它不是生产Redis配置；正式服务器请使用根目录《BiSeNet_Celery诊断部署与字段说明.md》的Redis配置。默认启用旧评分缺项回退，保证当前服务能返回完整分数。

`request_scores_example.json`已指向包内one三张样例，发送到诊断接口即可；正式三项接口也可使用同一输入。旧推理接口仍会拒绝，不会把请求挂到未消费的旧队列。

独立打包运行验收：`STANDALONE_DIAGNOSTIC_ACCEPTANCE.json`。
HTTP提交、队列执行、查询验收：`LOCAL_HTTP_ACCEPTANCE.json`。

当前返回为“新BiSeNet量化 + 旧参考缺项回退”的兼容分，1000例未重跑；`reference_matches_new_preprocessing=false`，不能据此宣称新参考已经标定。
