# 独立水光三项评分更新（当前部署口径）

本文件覆盖旧文档中固定样例回退、油光三指标权重以及零目标不可评分的描述。

## 评分规则

- 毛孔与色斑原有测量和参考规则保持；均只使用当前正面照片的真实证据。
- 毛孔/油光零目标：有效区域至少100像素，质量为PASS或无阻断原因的WARNING，区域目标证据完整且为零，返回100分、未见明显。原始质量警告保留在trace中；缺测、未覆盖、低质量、未知定位不视为零。不存在的目标P50/平均强度仍保持空值，不伪造统计量。
- 表面油光整体及九区统一采用面积双指标：状态分=油光面积状态分×25/45＋高强度油光面积状态分×20/45。组件分先用同区域、同测量定义的已有V3参考计算并执行原严重程度保护，再组合、取整和划分等级。
- 平均油光强度保留为测量证据，不参与当前组合评分。左/右面颊平均强度原参考仅48/47个有效开发样本，未启用低样本数参考；面积两项各有左526、右525个开发样本和各140个确认样本。
- 全脸分独立计算，不平均区域分；不混入卟啉、Brown、UV，不从另一个受检者或样例复制分数。
