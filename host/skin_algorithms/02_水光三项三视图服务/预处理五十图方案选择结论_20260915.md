# 50张预处理对照：方案选择结论

## 选择

视觉效果方案选定：**BiSeNet / ResNet18人脸部件解析，512输入，发布者原始权重及输入归一化；保留独立MediaPipe眉毛30px排除。** 不再围绕本组照片添加暗度、连通、长宽比或厚度规则。

该结论是本轮固定50张上的技术选择，不是正式云端部署完成。模型权重用途边界仍需核实；本轮不改变正式服务默认值，不启动评分、不重跑1000例。

## 验证范围

固定种子20260915050，从已有1000例输入清单按SHA排序后随机抽取50张。选图先冻结，全部50张原图SHA运行前后核对，无替换、无检测/评分执行。每张均生成原图及四套完整对照，主代理逐张视觉查看；第19、37张另以1024原分辨率放大复核。

## 淘汰与排序

| 方案 | 结果 | 证据 |
|---|---|---|
| 旧版规则预处理 | **淘汰，不得再作为最终候选** | 第2、8、25、31、32、34、39、42等图存在明确正常额头大块缺失；已有two正面缺陷也未修复。以上是明确反例，不是完整发生率统计。 |
| MediaPipe多类别＋Hair512，对齐后分割 | 不选为最终方案 | 无旧版同等级成片暗纹挖空的普遍表现，但第37张额头上部被几何范围截去；第7、11、40张眼镜覆盖区仍进入分析范围；细发边界也有限。 |
| MediaPipe多类别＋Hair512，原图分割后映射 | 不选为最终方案 | 保留了头部上下文但未一致解决上述覆盖问题，未呈现足够稳定的总体优势。 |
| BiSeNet人脸解析 | **本轮视觉最佳，选作接入候选** | 50张中未观察到类似旧版大块正常皮肤误排；额头覆盖更贴近发际；刘海、眼镜区域处理整体更一致。 |

“未观察到”只针对这50张，不保证未来照片零失败，不虚构像素级准确率或统计显著性。

## 必须保留的缺陷与输入限制

- 第19张复杂头饰：BiSeNet把部分额前彩珠纳入皮肤，是实际误纳入。不能把这张直接用于皮肤评分；此类遮挡需要移除后重拍或质量拒绝。它不是正常皮肤误删，但不能隐瞒成“50张全场景无错误”。
- 第7、11、40张眼镜：选定方案对眼镜区域排除更充分，但拍摄规范仍应要求摘除眼镜，不能把镜片后的皮肤当可靠测量。
- 模糊、强光、近距离裁切及浓妆样例的质量限制继续保留；Mask连贯不代表输入满足检测质量。
- 极细发丝与短胡茬仍不能声称完整逐像素识别。本轮选择不授权恢复旧版大块排除作为补丁。

## 后续接线约束

先核实选定权重的来源和用途，再在独立沙箱接入真实三项检测；低质量/遮挡输入不能静默给健康高分。新预处理与旧参考不匹配时，只允许标注清楚的诊断评分对照，不得作为已校准正式结果。评分参考是否重建，另按用户授权执行。

结果目录：`evaluation_v1/case_01`至`case_50`。选择清单：`selection.json`。运行回执：`evaluation_v1/receipt.jsonl`。所有淘汰方案的源码和图片保留，所谓“移除”指退出候选与正式调用，不是删除可回溯证据。
