# 预处理模型路线审查：尚未发布

## 当前真实结论

用户指出旧版刘海排除更充分，但旧版额头大块误排不可接受。纯MediaPipe多类别模型虽然保留正常皮肤，却存在细发漏排，已撤销其最终验收结论。不能简单选择“保留更多皮肤”的方案，也不能取旧版误排Mask的并集。

## 本轮新增证据

1. 官方HairSegmenter 512×512已对同一固定16张做本地预处理对照。来源：`https://storage.googleapis.com/mediapipe-models/image_segmenter/hair_segmenter/float32/latest/hair_segmenter.tflite`。SHA256：`2628cf3ce5f695f604cbea2841e00befcaa3624bf80caf3664bef2656d59bf84`。官方模型卡明确Apache 2.0许可。没有上传照片，没有执行三项检测或评分。
2. 主代理查看全部16张四联图：probe_08刘海排除有改善；two正面未复现旧版额头大片误排。但one右侧和two侧面有额部范围争议，细长垂发仍非完整识别。不能认定最终通过。
3. 开源BiSeNet/ResNet18人脸解析完成同样16张研究评估。来源作者：`https://github.com/yakhyo/face-parsing`；预处理严格按作者RGB/ImageNet归一化/512输入/argmax及最近邻恢复，无重新训练、无样例专用规则。当前仅检查关键案例，未完成全套视觉验收。训练数据及权重用途边界待核实，权重不得并入正式交付。
4. 生成16张官方模型分歧图：绿色表示候选皮肤上两模型不冲突，红色表示都判头发，橙色表示多类别皮肤与专用毛发模型冲突。该图只是诊断，绿色不等于人工真值，橙色不能当作已确认头发或健康皮肤。
