# 人脸七区联调说明

## 模型与来源

设备框保持V5 REAL-ONLY YOLOX-S，接触点保持V5 MobileNetV3-Small，FP32 ONNX和原哈希不变。新增MediaPipe CPU分区在设备模式逐帧运行，不修改人脸拍照模式。

关键点模型从 `pc_demo/models/face_landmarker.task` 复制，SHA256为 `64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff`，3758596字节，纳入启动哈希校验。运行使用MediaPipe 0.10.35，无新依赖安装、无下载。许可证沿用MediaPipe相关授权，对外发布前核验模型分发授权及LICENSE原文。

参考旧 `src/face_region_mapper.py` 与 `src/integrated_pipeline.py` 的关键点和脸部轮廓定义；七区映射是本次新写的几何近似，不是旧粗分区的逐像素复刻。模型可能输出额外虹膜点，本功能只使用前468点。

## 页面

选择“旧仪器检测”后，可开关七区透明叠加、468关键点和接触点。七区为额头、眼周、鼻部、本人左脸颊、本人右脸颊、嘴周、下巴。镜像仅影响显示，所有API坐标基于EXIF校正后的未镜像原图。

七区由关键点多边形生成同一张互斥标签图；眼睛开口和嘴唇排除。v2沿脸部纵轴将上缘最多上扩脸高20%，向太阳穴平滑减弱，不扩张下巴和下半脸；参考旧工作树 `src/frame_preprocessing.py` 的保留边界思路，但不直接复用其各方向膨胀，以免把脸周背景一并纳入。脸内未分配像素按最近区域补齐，保证估计轮廓内除眼睛和嘴唇外连续覆盖。上缘是几何估计，不是发际线或皮肤分割；不同额头、刘海和侧脸仍可能误覆盖头发。内部标签图分辨率最长边640，边界精度有限。页面轮廓来自该标签图，填充采用evenodd保留孔洞。

接触点不存在、无脸、多人、明显侧脸、小脸、区域交界附近均可返回unknown；脸外为outside_face，眼睛或嘴唇排除区为excluded。侧脸保护是几何启发式，不是标定的角度门禁；大幅遮挡、仪器遮脸、头发和皮肤边界仍需实拍验证。没有深度信息，因此“接触点区域”仅指2D投影落点，不证明实际接触皮肤。

## 接口与后续皮肤算法

设备帧新增 `face_regions`：`schema_version=face-regions-7-v2`、valid、reason、468个像素坐标landmarks、七区regions（id/name/color/rings）、contact_region、forehead_boundary（几何扩展标记）。顶层contact_region同步，耗时新增 `timings_ms.total_with_regions`。无效帧输出空分区，不沿用上一帧。

未来皮肤算法可按同一frame_id和未镜像坐标使用这些区域进行ROI评估。本次没有接入皮肤诊断、产品推荐或治疗规则，也未实现三维重建、分区ROI导出或参考图中的多视窗展示。区域图仅供工程联调，不代表水光注射、能量设备等治疗的安全区域或适应证。

## 本次验证

10项后端回归通过（含额头沿头部轴扩展、脸内无未分配孔洞和眼唇排除）；真实模型正面图输出468点及七个非空区域，空白图清空。已查看同图v1/v2叠加对比，确认额头覆盖提升、区域空隙填齐。仍需摄像头下人与旧仪器同时出现、遮挡和区域边界的现场验收；未进行临床或皮肤诊断准确性验证。
