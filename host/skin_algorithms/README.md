# DermaVision 智能皮肤检测与图像采集系统

本目录提供可独立部署和组合使用的三套视觉AI源码，覆盖图像采集、拍摄质量控制、目标与姿态检测、皮肤问题量化、区域评分以及云端任务处理。

## 一、作品组成

| 模块 | 主要能力 | 输入 | 主要输出 |
|---|---|---|---|
| `01_V2单双输入十二项稳定版` | 普通单RGB与机构四光源皮肤检测；12项检测、11模块评分、云端Worker、CPU评分汇总及可选双Word报告 | 单张RGB，或RGB/PP/CP/UV四光源采集 | 检测图、JSON、CSV、评分与严重程度、可选报告 |
| `02_水光三项三视图服务` | 三视图自动识别；毛孔、可见色斑、表面油光检测；整体及原生分区评分 | 三张顺序不限的左侧、正面、右侧RGB照片 | 三项整体评分/严重程度及9/8/9个分区评分JSON |
| `03_目标检测与自动拍照` | 人脸检测与角度估计、稳定门禁、自动拍照；旧仪器目标框、接触点和人脸七区显示 | 浏览器摄像头实时画面 | 角度/质量状态、自动保存照片、目标框及区域结果 |

三个模块均保留自己的模型、配置、依赖锁、技术文档、来源说明和完整性清单，可单独部署。它们不是必须同时启动的单体程序，实际产品可按设备和业务流程选择组合。

## 二、典型流程

### 普通用户三视图采集与水光三项分析

```text
浏览器摄像头
  → 人脸与角度检测
  → 稳定门禁和自动拍照
  → 左侧/正面/右侧三视图
  → 毛孔、可见色斑、表面油光分析
  → 整体与分区评分JSON
```

### 机构四光源皮肤检测

```text
RGB_M / PP_M / CP_M / UV(365)_M
  → 光源角色与配准检查
  → 十二项皮肤检测
  → 十一模块评分
  → JSON / CSV / 检测图 / 可选双Word报告
```

### 设备目标辅助

```text
摄像头画面
  → 旧仪器目标检测
  → 接触点估计
  → 人脸七区归属与网页叠加
```

## 四、环境与启动原则

推荐基础环境：

- Ubuntu 22.04 / WSL2，x86_64；
- Python 3.10；
- 使用各模块自身的 `pyproject.toml` 和 `uv.lock`；
- GPU模块推荐NVIDIA GPU，CPU模式用于接口和功能检查；
- 云端异步任务按模块文档配置Redis与Celery。

进入相应模块后执行：

```bash
uv sync --frozen
```

不要把三个模块安装到同一个已有虚拟环境中。建议每个模块建立独立 `.venv`，以避免ONNX Runtime、PyTorch和其他视觉依赖互相覆盖。

## 五、完整性校验

统一目录校验：

```bash
python3 verify_all.py
```

分模块校验：

```bash
python3 01_V2单双输入十二项稳定版/scripts/verify_submission_snapshot.py
python3 02_水光三项三视图服务/scripts/verify_package.py
python3 03_目标检测与自动拍照/scripts/verify_submission.py
```

`PACKAGE_MANIFEST.json`记录统一目录文件的SHA256和大小；各模块也有自己的清单及验收回执。校验脚本不会启动GPU推理，也不会上传图片。

## 七、使用边界

本项目输出的是图像检测、外观量化、拍摄质量与区域评分结果，不直接给出注射点、剂量、治疗深度或医疗诊断。人脸检测与空间锁定不等于身份认证；目标或接触点在二维图像中的位置也不等于真实物理接触证明。

部署到正式服务器或硬件前，应按照各模块文档完成目标机器依赖、摄像头、GPU/驱动、消息队列、数据权限和真实样本验收。
