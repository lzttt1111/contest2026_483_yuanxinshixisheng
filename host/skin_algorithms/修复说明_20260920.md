# 固定样例评分与正面拍照修复

## 当前实现（覆盖旧部署文档）

水光已完全停用固定样例分数回退。即使设置SHUIGUANG_LEGACY_SCORE_FALLBACK=1，也不会读取legacy_score_fallback.json补分；该文件只作为历史记录保留。当前图像的实际指标仍使用已有参考计算，不重新跑1000例。缺少参考或有效证据的区域，score/severity保持null，原因留在内部scores_internal.json。接口合同字段保持不变。

评分版本更新为current-image-evidence-only-20260920-1，旧任务ID与新评分身份不同，会返回TASK_ID_CONFLICT，需新任务ID。正式/诊断路径都核对BiSeNet模型资产，健康接口legacy_score_fallback固定为false。尚未重新校准的参考仍不得宣称已匹配新预处理。

独立PC拍照新增front（0°），与left/right共三个槽位。默认侧面±45°、误差5°。三个视角可按任意顺序采集，界面按左｜正｜右展示。front支持下载及reset?side=front单槽重拍，重拍保留左右图和旧磁盘记录。每个有效采样的原始与平滑角度必须同槽达标，原始角度不达标立即清空稳定计时。保存字节仍来自触发时收到的同一JPEG。
