# 完整产物示例：先检查有效域

合成参考皮肤为2×2全1，当前有效Mask只保留左上像素；检测Mask却保留第一行两个像素，候选中心位于右上。

| 阶段 | 像素数/结果 | 解释 |
|---|---|---|
| 参考皮肤 | 4 | 参考来源真实性需另证 |
| 有效域 | 1，保留率25% | 低于本例75%门槛 |
| 有效域内支持 | 1 | 剔除越域像素后计数 |
| 越域检测 | 1 | 检测Mask与有效域不一致 |
| 候选中心 | 在有效域外 | 正式实例与域不一致 |

最小复现固定上述Mask和候选，不改检测阈值。诊断先核对预处理绑定、变换和过滤原因；不能通过放宽检测器弥补被误排的皮肤。变更方案仅作为建议，授权后先修对应层，再对困难图及正常图定向回归。
