# 完整产物示例：三人物实验协议

合成清单：p1/s1/c1在train，p2/s2/c2在validation，p3/s3/c3在test；三者摘要均不同。

实验配置：使用validation选择checkpoint，train:a用于校准及合成来源，test冻结至候选选定后使用。人物、Session、哈希和近重复cluster四层均无跨集重叠。

基线对照表应按相同验证集记录设备框误差、ROI覆盖、关键点误差及最终区域可用性，不以不同数据集的AP直接排序。本例没有模型预测，因此精度栏为未运行，不能填写历史高分。

困难样本队列：来自train中上游ROI变化大、热图不确定或遮挡严重的样本；不得从test取素材。模型选择结论为“划分协议可进入后续实验，但每集一个人物不足以证明泛化”。操作仍只读，不启动训练。
