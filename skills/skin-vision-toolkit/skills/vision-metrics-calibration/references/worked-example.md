# 完整产物示例：量化与候选配置

合成输入有效域100像素、支持20像素、四个实例值[1,2,3,4]，实例单位为图像域测量。

| 指标 | 数值 | 来源 |
|---|---:|---|
| 数量 | 4 | 实例列表长度 |
| 覆盖率 | 0.20 | 20/100 |
| 每10万像素密度 | 4000 | 4×100000/100 |
| P50 | 2.5 | 原始实例线性插值 |
| P90 | 3.7 | 原始实例线性插值 |

分区正式值只取本项选择的主视角；补充视角有发现要展示，但不累加成全脸唯一总数。没有对应证据时不作病灶去重声明。

配置示例：status=candidate，score_enabled=false，metric_version=example-v1，weight_source=not_defined，physical_scale=null。没有标定任务/参考分布/医生确认时不硬造分数。若声明分母100、实际仅检测50，应拒绝扩张分母。对[1,2,3,100]，P90应重算为70.9，不接受平均子集分位数46.1。
