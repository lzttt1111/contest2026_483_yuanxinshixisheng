# 完整产物示例：同源报告发布

合成source与report投影均为count=2、coverage=0.25；证据文件为不含人物的文本资产。

映射：检测count→网页目标数→报告数量；coverage→覆盖率字段；图片/证据引用从本次索引读取。只调整布局，不运行推理或重算评分。

同源结果：两份JSON相等，证据文件实际SHA记录于检查回执。若报告count变成20，即使版式正常也不能通过；包外../outside.txt引用应在读取前拒绝。

展示产物示例：“本次检出2个候选，图像有效域覆盖25%；结果仅限本次成像和有效区域。”真实Word/PDF还需在隔离副本上实际渲染并检查表格、字体、单位、分页和图片；本例不冒充已生成正式医生报告。

重建验收：明确渲染入口不加载模型，对真实目录先复制后运行。函数名含audit并不证明只读。
