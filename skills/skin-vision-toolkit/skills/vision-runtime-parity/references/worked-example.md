# 完整产物示例：张量与坐标对拍

数值摘要source=[0.1,0.2,0.3]，target=[0.1001,0.2001,0.3001]，显式容差0.001，实际/声明provider均为CPU。最大误差约0.0001，通过仅限该摘要；不能称完整ONNX或实板通过。

坐标合同：letterbox scale=0.5、pad=[0,10]。模型点[5,20]还原为原图[10,20]；若错误忽略上padding，得到[10,40]，误差20像素，应失败。再对width=100反镜像，应为[89,20]。坐标均是图像像素，不是深度或真实接触。

完整迁移清单还需模型SHA、颜色/布局、归一化、输出头、解码、NMS、代表样本、量化来源、实际provider和冷/热启动回执。本例只展示如何定位差异层，不运行模型转换、量化或部署。
